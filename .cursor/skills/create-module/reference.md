## Шаблон: Практика с .ipynb

README.md — как у лабораторной, но с указанием на готовый ноутбук.

Ноутбук:
1. Title cell (Markdown) — название, модуль, цель.
2. Context cells — готовый код и markdown с реальным сценарием.
3. Task cells (Markdown) — `## Задание N` с инструкциями.
4. Empty code cells — для студента.

Файлы: `README.md`, `practice-*.ipynb`

## Чеклист модуля

### Структура

- [ ] Директория модуля создана (`course/NN-name/`)
- [ ] README модуля (обложка) создан с секциями «Чему вы научитесь» и «Итоги модуля»
- [ ] `summary.md` (конспект) создан — тезисы, команды, ошибки
- [ ] Все юниты имеют директории с правильными именами
- [ ] Все `README.md` написаны
- [ ] Все `solution.md` написаны (для лабораторных)
- [ ] Все `check.sh` написаны (для тренажёров и лабораторных)
- [ ] Все `break.sh` написаны (для диагностик)
- [ ] Все `.ipynb` созданы (для практик с ноутбуками)

### Навигация

- [ ] Каждый `README.md` начинается с `← Назад | Оглавление | Далее →`
- [ ] Каждый `README.md` заканчивается с `← Назад | Оглавление | Далее →`
- [ ] Ссылки «Назад» и «Далее» указывают на правильные юниты
- [ ] `course/README.md` обновлён — модуль и все юниты перечислены

### Контент

- [ ] Весь контент на русском языке
- [ ] Каждый урок имеет секцию «Частые ошибки»
- [ ] Вставки-сравнения добавлены (если указаны в программе)
- [ ] Тесты и лабораторные следуют принципу «снежного кома»
- [ ] Терминальный вывод в ```bash блоках, не скриншотами
- [ ] Подсказки в лабораторных — нарастающей детализации

### Справочники

- [ ] Новые термины добавлены в `course/references/glossary.md`
- [ ] Новые команды терминала добавлены в `course/references/terminal-commands.md`
- [ ] Новые команды инструментов добавлены в соответствующий cheatsheet

### Качество

- [ ] check.sh скрипты идемпотентны (безопасно запускать повторно)
- [ ] check.sh возвращают exit code 0 при успехе, != 0 при ошибке

- [ ] Эталонные решения полны и проверяемы
