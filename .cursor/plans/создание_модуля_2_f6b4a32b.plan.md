## Тезисный план юнитов

### 01 — Переключение глобальной версии (Урок)

- **Цель:** научить устанавливать версию Python по умолчанию для всей системы.
- **Ключевые команды:** `pyenv global <version>`, `pyenv global`, `pyenv global system`.
- **Содержание:** что такое глобальная версия, файл `~/.pyenv/version`, как сбросить на system.
- **Вставка-сравнение:** pyenv vs conda (подход к глобальной версии).
- **Частые ошибки:** забыть, что global влияет на все терминалы; путать global и system.
- **Опирается на:** Модуль 1 (установка pyenv, установка версий).

### 02 — Локальная версия для проекта (Урок)

- **Цель:** научить привязывать версию Python к конкретному проекту.
- **Ключевые команды:** `pyenv local <version>`, файл `.python-version`.
- **Содержание:** зачем нужна local-версия, как работает `.python-version`, наследование в поддиректориях, `pyenv local --unset`.
- **Частые ошибки:** забыть добавить `.python-version` в git; не понимать, что local перекрывает global.
- **Опирается на:** 01 (глобальная версия). **Подготавливает:** 04 (приоритеты).

### 03 — Версия для текущей сессии (Урок)

- **Цель:** научить временно переключать версию Python в рамках одной сессии терминала.
- **Ключевые команды:** `pyenv shell <version>`, `pyenv shell --unset`, переменная `PYENV_VERSION`.
- **Содержание:** когда полезна shell-версия, что такое `PYENV_VERSION`, отличие от local/global.
- **Частые ошибки:** ожидать, что shell-версия сохранится после закрытия терминала; забыть сбросить shell-версию.
- **Опирается на:** 01, 02. **Подготавливает:** 04.

### 04 — Приоритет версий (Урок)

- **Цель:** объяснить цепочку приоритетов: shell > local > global > system.
- **Содержание:** полная схема разрешения версии в pyenv, команда `pyenv version` для диагностики, эксперимент по демонстрации приоритета.
- **Вставка-сравнение:** pyenv vs asdf (аналогичная система приоритетов).
- **Частые ошибки:** не понимать, почему `pyenv version` показывает не ту версию, что ожидалась; не знать, как узнать источник текущей версии.
- **Опирается на:** 01, 02, 03. **Подготавливает:** тест и лабораторную.

### 05 — Тест: переключение версий (Тест)

- **Охватывает:** уроки 01-04 (все три уровня переключения + приоритеты).
- **Принцип «снежного кома»:** включает вопросы и по Модулю 1 (установка pyenv, `pyenv versions`).
- **Формат:** ~10 вопросов с вариантами ответов.

### 06 — Лабораторная: переключение версий (Лабораторная)

- **Задание:** настроить глобальную, локальную и сессионную версии Python, продемонстрировать приоритеты.
- **Снежный ком:** задания включают установку версии (Модуль 1) + переключение (Модуль 2).
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Подсказки:** 3 уровня нарастающей детализации.

### 07 — Удаление версии Python (Урок)

- **Цель:** научить удалять ненужные версии Python из pyenv.
- **Ключевые команды:** `pyenv uninstall <version>`, `rm -rf ~/.pyenv/versions/<version>`.
- **Содержание:** когда удалять, что происходит с local/global при удалении, очистка.
- **Частые ошибки:** удалить версию, привязанную к `.python-version`; не обновить global после удаления.
- **Опирается на:** 01, 02, 04.

### 08 — Обновление и деинсталляция pyenv (Урок)

- **Цель:** научить обновлять pyenv и при необходимости полностью удалять.
- **Ключевые команды:** `cd ~/.pyenv && git pull`, удаление строк из `.bashrc`, `rm -rf ~/.pyenv`.
- **Содержание:** зачем обновлять (новые версии Python), как обновить (git pull), полная деинсталляция, что остаётся после удаления.
- **Частые ошибки:** забыть удалить строки из `.bashrc`; не понимать, что после деинсталляции pyenv установленные версии Python исчезнут.

### 09 — Диагностика: python не найден после установки pyenv (Лабораторная-диагностика)

- **Сценарий:** коллега установил pyenv, но `python` не находится в shell.
- **Причина:** не настроена инициализация pyenv в `.bashrc` / `.profile`.
- **break.sh:** удаляет строки инициализации pyenv из конфигурации shell.
- **Файлы:** `README.md`, `break.sh`, `solution.md`.
- **Краевой случай #2** из программы.

### 10 — Итоговая лабораторная по pyenv (Лабораторная)

- **Задание:** комплексная задача, объединяющая весь Модуль 1 и Модуль 2.
- **Снежный ком:** установка версий, переключение global/local/shell, проверка приоритетов, удаление.
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
