## Тезисный план юнитов

### 01 — Ядра (kernels): что это, какие бывают, как переключить (Урок)

- **Цель:** объяснить концепцию ядра Jupyter и роль ядра в выполнении кода в ноутбуке.
- **Ключевые понятия:** ядро (kernel), ipykernel, выбор ядра в UI Jupyter.
- **Содержание:** ядро = интерпретатор Python (или другой язык); связь ядра с venv; переключение ядра через Kernel → Change kernel.
- **Частые ошибки:** не понимать, что код выполняется в окружении ядра, а не в терминале; путать «активированный venv в терминале» и «ядро, с которым работает Jupyter».
- **Опирается на:** модуль 6 (Jupyter, интерфейс), модули 4–5 (venv). **Подготавливает:** регистрацию venv как ядра.

### 02 — Регистрация venv-окружения как ядра Jupyter (Урок + тренажёр)

- **Цель:** установить ipykernel в venv и зарегистрировать окружение как ядро Jupyter.
- **Ключевые команды:** `pip install ipykernel`, `python -m ipykernel install --user --name=... --display-name=...`, `jupyter kernelspec list`.
- **Содержание:** пошаговая регистрация venv; параметры `--name` и `--display-name`; проверка в Jupyter UI.
- **Файлы:** `README.md`, `check.sh`.
- **Частые ошибки:** забыть активировать venv перед установкой ipykernel; установить ipykernel в системный Python вместо venv.
- **Опирается на:** 01, модуль 6. **Подготавливает:** управление ядрами.

### 03 — Управление ядрами: список, удаление (Урок)

- **Цель:** научиться просматривать зарегистрированные ядра и удалять ненужные.
- **Ключевые команды:** `jupyter kernelspec list`, `jupyter kernelspec remove <имя>`.
- **Содержание:** где физически лежат ядра; удаление ядра через CLI; последствия удаления (открытые ноутбуки).
- **Частые ошибки:** удалить ядро, которое используется открытыми ноутбуками; путать имя ядра и display-name.
- **Опирается на:** 01, 02. **Подготавливает:** тест и лабораторную.

### 04 — Тест: ядра, регистрация, переключение (Тест)

- **Охватывает:** уроки 01–03 (ядра, ipykernel, регистрация venv, управление ядрами).
- **Принцип «снежного кома»:** вопросы по модулю 6 (Jupyter, venv) и модулям 4–5.
- **Формат:** ~10 вопросов с вариантами ответов.

### 05 — Лабораторная: ядра, регистрация, переключение (Лабораторная)

- **Задание:** создать venv, установить Jupyter и ipykernel, зарегистрировать venv как ядро, переключить ядро в ноутбуке, проверить окружение.
- **Снежный ком:** venv, pip, pyenv, Jupyter из модулей 4–6.
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Подсказки:** 3 уровня нарастающей детализации.

### 06 — Диагностика: Jupyter использует системное ядро, а не venv (Лабораторная-диагностика)

- **Цель:** воспроизвести и исправить ситуацию, когда Jupyter запущен из venv, но ноутбук использует системный Python (ядро по умолчанию).
- **Содержание:** `break.sh` создаёт venv, устанавливает Jupyter, но не регистрирует venv как ядро; студент выявляет проблему и регистрирует ядро.
- **Файлы:** `README.md`, `break.sh`, `solution.md`.
- **Краевой случай** (по программе курса, таблица «Краевые случаи»): №4.
- **Опирается на:** 01, 02, 03.

### 07 — Диагностика: несколько Jupyter-серверов на разных портах (Лабораторная-диагностика)

- **Цель:** разобраться с конфликтом, когда запущено несколько экземпляров Jupyter на разных портах; путаница, какой сервер/порт использовать.
- **Содержание:** `break.sh` имитирует или описывает сценарий с несколькими серверами; студент диагностирует (jupyter --runtime-dir, порты, процессы) и принимает решение.
- **Файлы:** `README.md`, `break.sh`, `solution.md`.
- **Ключевые команды:** `jupyter notebook --port N`, `jupyter notebook list`, `ps`, `lsof`.
- **Краевой случай** (по программе курса): №7.
- **Опирается на:** модуль 6 (запуск Jupyter), 01–03.
