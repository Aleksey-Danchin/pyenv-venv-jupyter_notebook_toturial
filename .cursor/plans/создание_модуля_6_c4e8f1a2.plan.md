## Тезисный план юнитов

### 01 — Что такое Jupyter Notebook (Урок)

- **Цель:** объяснить назначение Jupyter Notebook и его место в экосистеме Python.
- **Ключевые понятия:** Jupyter Notebook, ноутбук (notebook), интерактивная разработка, ячейки.
- **Содержание:** что такое Jupyter, зачем ноутбуки (смесь кода и документации, воспроизводимость), откуда название.
- **Частые ошибки:** путать ноутбук с обычным .py-скриптом; не понимать, что Jupyter — это сервер + браузерный интерфейс.
- **Опирается на:** модули 0–5 (Python-среда, pyenv, pip, venv). **Подготавливает:** установку Jupyter в venv.

### 02 — Установка Jupyter внутри venv (Урок + тренажёр)

- **Цель:** установить Jupyter (jupyter, notebook) в виртуальное окружение и проверить установку.
- **Ключевые команды:** `pip install jupyter notebook`, `jupyter --version`, `which jupyter`.
- **Содержание:** пошаговая установка в активированном venv, проверка версии.
- **Файлы:** `README.md`, `check.sh`.
- **Опирается на:** модуль 4–5 (venv, pip install). **Подготавливает:** запуск сервера.

### 03 — Запуск notebook-сервера, интерфейс браузера (Урок)

- **Цель:** научиться запускать Jupyter Notebook и ориентироваться в браузерном интерфейсе.
- **Ключевые команды:** `jupyter notebook`, `jupyter notebook --no-browser`, `jupyter notebook --port 8889`.
- **Содержание:** как запустить сервер, что такое token/пароль, файловый менеджер, вкладки, отключение.
- **Медиа:** скриншоты интерфейса (по конвенции: терминал — текст; GUI — скриншоты).
- **Частые ошибки:** не понять, что Jupyter — это сервер; забыть Ctrl+C для остановки.
- **Опирается на:** 01, 02. **Подготавливает:** работу с ноутбуками и ячейками.

### 04 — Создание, переименование, удаление ноутбуков (Урок)

- **Цель:** уверенно управлять файлами ноутбуков (.ipynb) через интерфейс.
- **Содержание:** создание нового ноутбука, переименование через UI, удаление (в т.ч. восстановление из корзины, если доступно).
- **Частые ошибки:** удалить ноутбук без бэкапа; путать имя файла и заголовок вкладки.
- **Опирается на:** 03. **Подготавливает:** работу с ячейками.

### 05 — Типы ячеек: Code, Markdown, Raw (Урок)

- **Цель:** понимать разницу между типами ячеек и уметь их переключать.
- **Ключевые понятия:** Code cell, Markdown cell, Raw cell.
- **Содержание:** Code (исполняемый Python), Markdown (документация, формулы), Raw (без обработки).
- **Частые ошибки:** писать код в Markdown; забывать Run для выполнения Code.
- **Опирается на:** 04. **Подготавливает:** 06 (горячие клавиши), тест и лабораторную.

### 06 — Базовые горячие клавиши (Урок)

- **Цель:** освоить основные горячие клавиши для эффективной работы.
- **Ключевые комбинации:** Enter / Shift+Enter, Ctrl+Enter, Esc / Enter (режимы), A/B (вставить ячейку), D,D (удалить), Y/M/R (смена типа), Ctrl+S и др.
- **Содержание:** режим команд vs режим редактирования; таблица клавиш.
- **Частые ошибки:** не различать режимы; привыкнуть только к мыши.
- **Опирается на:** 05. **Подготавливает:** тест и лабораторную.

### 07 — Тест: установка, запуск, ячейки (Тест)

- **Охватывает:** уроки 01–06 (Jupyter, установка, запуск, интерфейс, типы ячеек, горячие клавиши).
- **Принцип «снежного кома»:** вопросы по venv, pip, pyenv из модулей 4–5.
- **Формат:** ~10 вопросов с вариантами ответов.

### 08 — Лабораторная: установка, запуск, ячейки (Лабораторная)

- **Задание:** создать venv, установить Jupyter, запустить сервер, создать ноутбук, выполнить ячейки разных типов.
- **Снежный ком:** venv, pip, pyenv.
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Подсказки:** 3 уровня нарастающей детализации.

### 09 — Магические команды (Урок)

- **Цель:** познакомить с магическими командами IPython/Jupyter.
- **Ключевые команды:** `%timeit`, `%run`, `!команда` (shell), `%env`, `%pwd`, `%ls`, `%%time` и др.
- **Содержание:** что такое magics; line vs cell magics; примеры использования.
- **Частые ошибки:** путать `!` и `%`; забывать, что `!pip` — это shell, не pip текущего ядра.
- **Опирается на:** 05, 06. **Подготавливает:** практикум (модуль 8).

### 10 — Экспорт ноутбука (HTML, PDF, .py) (Урок)

- **Цель:** уметь экспортировать ноутбук в разные форматы.
- **Ключевые команды:** `jupyter nbconvert --to html`, `--to pdf`, `--to script` (.py); File → Download as.
- **Содержание:** nbconvert, зависимости (pandoc, LaTeX для PDF), экспорт через UI.
- **Частые ошибки:** не установить texlive для PDF; путать .py экспорт с полным воспроизведением ноутбука.
- **Опирается на:** 01–06. **Завершает модуль.**
