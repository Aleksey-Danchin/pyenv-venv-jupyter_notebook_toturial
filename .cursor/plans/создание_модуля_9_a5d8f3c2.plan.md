## Тезисный план юнитов

### 01 — Что такое JupyterLab и чем отличается от Notebook (Урок)

- **Цель:** объяснить суть JupyterLab как наследника и замены Jupyter Notebook.
- **Ключевые понятия:** JupyterLab, Next-Generation Notebook Interface.
- **Содержание:** зачем JupyterLab; основные отличия от классического Notebook (модульный интерфейс, вкладки, расширяемость); сценарии, когда выбирать JupyterLab.
- **Вставка-сравнение:** Jupyter Notebook vs JupyterLab vs VS Code Notebooks — краткая секция в этом уроке.
- **Файлы:** `README.md`.
- **Опирается на:** модуль 6 (Jupyter Notebook), модуль 7 (ядра).

### 02 — Установка и запуск JupyterLab (Урок + тренажёр)

- **Цель:** установить JupyterLab в venv и запустить сервер.
- **Ключевые команды:** `pip install jupyterlab`, `jupyter lab`, `jupyter lab --port=8889`.
- **Содержание:** теория (jupyterlab как пакет, единый сервер для Notebook и Lab) + пошаговое выполнение: активация venv → pip install jupyterlab → jupyter lab; проверка доступности в браузере.
- **Файлы:** `README.md`, `check.sh`.
- **Опирается на:** модуль 6 (установка Jupyter), модуль 4–5 (venv), модуль 7 (ядра).

### 03 — Интерфейс: вкладки, терминал, файловый менеджер, просмотр данных (Урок)

- **Цель:** освоить элементы интерфейса JupyterLab.
- **Ключевые понятия:** боковая панель, вкладки, Launcher, встроенный терминал, файловый менеджер, просмотр CSV/изображений.
- **Содержание:** структура интерфейса; вкладки и перетаскивание; создание ноутбуков/терминала/текстовых файлов; встроенный терминал (какой shell, связь с venv); просмотр данных (CSV, изображения) без кода.
- **Файлы:** `README.md`.
- **Опирается на:** 01, 02; модуль 6 (ноутбуки, ячейки).

### 04 — Лабораторная: работа в JupyterLab (миграция с Notebook) (Лабораторная)

- **Цель:** перенести рабочий процесс с Jupyter Notebook на JupyterLab.
- **Содержание:** открыть существующий ноутбук из модуля 6–8; выполнить типичные действия (создание ячеек, запуск кода, терминал, просмотр файлов); убедиться, что ядро venv работает; сравнить опыт работы.
- **Принцип «снежного кома»:** venv, Jupyter, ядра, ноутбуки.
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Опирается на:** все юниты модуля 9, модули 6–8.
