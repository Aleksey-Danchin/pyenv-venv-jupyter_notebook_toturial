## Тезисный план юнитов

### 01 — Что такое pip и PyPI (Урок)

- **Цель:** объяснить назначение pip и роль PyPI в экосистеме Python.
- **Ключевые понятия:** pip, PyPI, менеджер пакетов.
- **Содержание:** связка pip↔Python, отличие pip от системного пакетного менеджера, что такое PyPI.
- **Частые ошибки:** путать pip с apt; не понимать, что pip связан с конкретным интерпретатором.
- **Опирается на:** модуль 0 (урок 05 — pip и site-packages), модули 1–2 (pyenv).

### 02 — Установка, удаление, обновление пакетов (Урок)

- **Цель:** освоить базовые операции pip: install, uninstall, upgrade.
- **Ключевые команды:** `pip install`, `pip uninstall`, `pip install --upgrade`, `pip show`.
- **Содержание:** установка по имени, по версии, по requirements; удаление; обновление пакетов.
- **Частые ошибки:** `pip install` без указания версии; глобальная установка вместо venv (предвосхищение модуля 4).
- **Опирается на:** 01. **Подготавливает:** 03 (requirements.txt).

### 03 — pip freeze, pip list и requirements.txt (Урок)

- **Цель:** научиться фиксировать и воспроизводить набор пакетов.
- **Ключевые команды:** `pip list`, `pip freeze`, `pip install -r requirements.txt`.
- **Содержание:** разница list/freeze; формирование requirements.txt; воспроизведение окружения.
- **Частые ошибки:** путать list и freeze; забывать freeze при коммите проекта.
- **Опирается на:** 02. **Подготавливает:** тест и лабораторную.

### 04 — Откуда берутся пакеты: PyPI, индексы, кеш (Урок)

- **Цель:** понять источник пакетов и механизмы загрузки.
- **Ключевые понятия:** индекс пакетов, кеш pip.
- **Ключевые команды:** `pip cache`, `pip config`, `--index-url`, `--no-cache-dir`.
- **Содержание:** PyPI как дефолтный индекс, альтернативные индексы, кеш загрузок.
- **Частые ошибки:** не знать, куда pip идёт за пакетами; проблемы при недоступности PyPI.
- **Опирается на:** 01, 02.

### 05 — Тест: pip-операции и requirements (Тест)

- **Охватывает:** уроки 01–04 (pip, PyPI, install/uninstall/upgrade, freeze/list, requirements, индексы).
- **Принцип «снежного кома»:** включает вопросы по модулям 0–2 (site-packages, pyenv, какая версия Python используется).
- **Формат:** ~10 вопросов с вариантами ответов.

### 06 — Лабораторная: pip-операции и requirements (Лабораторная)

- **Задание:** установить пакеты, сформировать requirements.txt, воспроизвести окружение.
- **Снежный ком:** использовать pyenv (версия Python), pip в контексте (предвосхищение venv).
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Подсказки:** 3 уровня нарастающей детализации.

### 07 — pip vs системный пакетный менеджер (apt) (Урок)

- **Цель:** чётко разграничить pip и apt, избежать конфликтов.
- **Содержание:** почему pip ≠ apt; что ставит apt (python3-*); риски смешивания.
- **Вставки-сравнения (по программе):** pip vs conda · pip vs pipx — краткие вставки в этот урок или в 01/02 по контексту.
- **Частые ошибки:** устанавливать Python-пакеты через apt; пытаться обновлять pip-пакеты через apt.
- **Опирается на:** 01, 02. **Завершает модуль.**
