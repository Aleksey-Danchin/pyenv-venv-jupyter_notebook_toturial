## Тезисный план юнитов

### 01 — Создание проекта с нуля (Тренажёр)

- **Цель:** пройти полную цепочку pyenv → venv → pip → jupyter → kernel пошагово.
- **Ключевые действия:** pyenv install/local, python -m venv, pip install jupyter ipykernel, jupyter kernelspec install, запуск jupyter.
- **Содержание:** пошаговое выполнение с проверкой на каждом этапе; почему именно такой порядок.
- **Опирается на:** модули 1–7. **Подготавливает:** 02.

### 02 — Тот же проект с JupyterLab (Тренажёр)

- **Цель:** воспроизвести/адаптировать сценарий 01 с JupyterLab вместо Notebook.
- **Ключевые действия:** pip install jupyterlab (в том же venv или отдельно), jupyter lab, проверка ядра.
- **Содержание:** отличия при установке/запуске; общие части (pyenv, venv, kernel).
- **Опирается на:** 01, модуль 9. **Подготавливает:** 03, 04.

### 03 — Переключение проекта на другую версию Python (Лабораторная)

- **Цель:** научиться мигрировать проект на новую версию Python.
- **Ключевые действия:** pyenv install новой версии, pyenv local, пересоздание venv, pip install -r requirements.txt, перерегистрация ядра.
- **Содержание:** порядок шагов; что ломается при неверной последовательности.
- **Файлы:** README.md, solution.md, check.sh.
- **Опирается на:** 01, 02, модули 2, 5, 7.

### 04 — Два проекта одновременно (Лабораторная)

- **Цель:** работать с двумя проектами с разными версиями Python и окружениями.
- **Ключевые действия:** два каталога, два .python-version, два venv, два ядра; переключение между ними.
- **Содержание:** организация рабочих каталогов; переключение pyenv local; переключение venv; переключение ядра в Jupyter.
- **Файлы:** README.md, solution.md, check.sh.
- **Опирается на:** 01–03, модули 2, 5, 7.

### 05 — Удаление проекта (Урок + тренажёр)

- **Цель:** корректно удалить проект: деактивация venv, удаление venv, удаление ядра, очистка pyenv local.
- **Ключевые действия:** deactivate, jupyter kernelspec uninstall, rm -rf venv/, удаление .python-version.
- **Содержание:** теоретическая часть (почему важен порядок) + пошаговое выполнение.
- **Файлы:** README.md, check.sh.
- **Опирается на:** 01–04. **Подготавливает:** 06.

### 06 — «Коллега прислал проект» (Лабораторная)

- **Цель:** воспроизвести окружение по requirements.txt и .python-version.
- **Ключевые действия:** скопировать файлы, pyenv install (по .python-version), venv, pip install -r requirements.txt, ipykernel, запуск.
- **Содержание:** полный сценарий онбординга; типовые проблемы (отсутствующий .python-version, устаревший requirements).
- **Файлы:** README.md, solution.md, check.sh.
- **Опирается на:** 01, модули 3, 5, 7, 10.

### 07 — Диагностика: конфликт pyenv local vs venv от другой версии (Лабораторная-диагностика)

- **Цель:** найти и исправить конфликт версий (pyenv local указывает на X, активированный venv построен на Y).
- **Ключевые действия:** break.sh создаёт воспроизводимую поломку; студент диагностирует (which python, python --version, pyenv version) и исправляет.
- **Файлы:** README.md, break.sh, solution.md.
- **Краевой случай** из программы курса (№5).
- **Опирается на:** модули 2, 5, 7.

### 08 — Финальная лабораторная (Лабораторная)

- **Цель:** пройти полный цикл «с нуля до воспроизведения» — снежный ком по всему курсу.
- **Содержание:** комплексное задание, объединяющее pyenv, venv, pip, requirements, Jupyter/JupyterLab, ядра, .gitignore, git (базово).
- **Файлы:** README.md, solution.md, check.sh.
- **Опирается на:** все модули 0–11.
