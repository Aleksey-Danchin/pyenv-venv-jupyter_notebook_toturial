## Тезисный план юнитов

### 01 — Что такое pyenv и зачем он нужен (Урок)

- **Цель:** объяснить, какую проблему решает pyenv и как он вписывается в Python-экосистему.
- **Ключевые понятия:** pyenv, менеджер версий Python, shim-механизм (ссылка на модуль 0).
- **Вставка-сравнение:** pyenv vs `apt install python3.x` — почему apt недостаточно.
- **Частые ошибки:** путаница pyenv с venv/virtualenv; попытка установить pyenv через pip.
- **Опирается на:** модуль 0 (PATH, shims, системный Python).

### 02 — Установка pyenv (Тренажёр)

- **Цель:** пошагово установить pyenv и настроить shell.
- **Ключевые действия:** установка зависимостей сборки (build-essential, libssl-dev и др.), установка pyenv через curl, настройка `.bashrc`, проверка `pyenv --version`.
- **Ключевые понятия:** зависимости сборки (build dependencies).
- **check.sh:** проверяет наличие pyenv в PATH и корректный вывод `pyenv --version`.
- **Подготавливает:** уроки 03–04 (работа с установленным pyenv).

### 03 — Установка версии Python через pyenv (Урок)

- **Цель:** научиться компилировать и устанавливать произвольную версию Python.
- **Ключевые команды:** `pyenv install <version>`, время компиляции, что происходит за сценой.
- **Частые ошибки:** не установлены зависимости сборки; прерывание длительной компиляции.
- **Опирается на:** юнит 02 (pyenv установлен).

### 04 — Просмотр доступных и установленных версий (Урок)

- **Цель:** научиться просматривать список версий и ориентироваться в нём.
- **Ключевые команды:** `pyenv install --list`, `pyenv versions`, `pyenv version`, звёздочка у активной версии.
- **Частые ошибки:** путаница между `pyenv version` и `pyenv versions`; поиск нужной версии в огромном списке (`grep`).
- **Опирается на:** юниты 02–03.

### 05 — Тест по pyenv (Тест)

- **Цель:** проверить понимание уроков 01–04 (принцип снежного кома — включая знания модуля 0).
- **Охват:** что такое pyenv, зачем нужен, установка, зависимости сборки, `pyenv install`, `pyenv versions`.
- **Формат:** 8–10 вопросов с вариантами ответов, ответы под спойлерами.

### 06 — Лабораторная: установка и просмотр версий (Лабораторная)

- **Цель:** самостоятельно установить указанную версию Python и подтвердить установку.
- **Задание:** установить конкретную версию, найти ее в списке, проверить путь.
- **Подсказки:** 3 уровня нарастающей детализации.
- **check.sh:** проверяет наличие нужной версии в `pyenv versions`.
- **Снежный ком:** задания затрагивают и темы модуля 0 (PATH, which, симлинки).

### 07 — Диагностика: pyenv install не компилирует (Лабораторная-диагностика)

- **Цель:** научиться диагностировать ошибку отсутствия зависимостей сборки.
- **Сценарий:** «коллега» удалил часть dev-пакетов, `pyenv install` падает с ошибкой.
- **break.sh:** удаляет один из ключевых -dev пакетов (напр. `libssl-dev`).
- **Симптомы:** ошибка компиляции при `pyenv install`.
- **Опирается на:** юнит 02 (зависимости сборки).
