## Тезисный план юнитов

### 01 — Практика: работа с данными и визуализацией (matplotlib) (Практика с .ipynb)

- **Цель:** набить руку в работе с данными и построении графиков в Jupyter.
- **Содержание:** pre-made ноутбук с примером данных (список/словарь), базовый matplotlib; задания — достроить график, изменить параметры, добавить подпись.
- **Файлы:** `README.md`, `practice-data-visualization.ipynb`.
- **Опирается на:** модуль 6 (Jupyter, ячейки, выполнение кода), модуль 7 (ядро venv).

### 02 — Практика: markdown-документация внутри ноутбука (Практика с .ipynb)

- **Цель:** освоить оформление ноутбука с помощью Markdown.
- **Содержание:** pre-made ноутбук с кодом и пустыми Markdown-ячейками; задания — добавить заголовки, списки, форматирование, описание шагов.
- **Файлы:** `README.md`, `practice-markdown-docs.ipynb`.
- **Опирается на:** модуль 6 (типы ячеек, Markdown), 01.

### 03 — Практика: использование магических команд в реальном сценарии (Практика с .ipynb)

- **Цель:** применить магические команды в практической задаче.
- **Содержание:** pre-made ноутбук с контекстом; задания — использовать `%timeit`, `%run`, `!pip`, `%env` и др. в сценарии (например, замерить время, проверить версии).
- **Файлы:** `README.md`, `practice-magic-commands.ipynb`.
- **Опирается на:** модуль 6 (магические команды), 01, 02.

### 04 — Практика: экспорт и воспроизведение ноутбука (Лабораторная)

- **Цель:** научиться экспортировать ноутбук в HTML/PDF/.py и воспроизводить его на другой машине.
- **Ключевые команды:** `jupyter nbconvert`, `pip install -r requirements.txt`, `jupyter notebook`.
- **Содержание:** экспорт в разные форматы; передача ноутбука коллеге (requirements.txt + .ipynb); воспроизведение окружения и запуск.
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Опирается на:** модуль 6 (экспорт), модули 4–5 (venv, requirements), модуль 7 (ядра).

### 05 — Итоговая лабораторная по Jupyter (снежный ком) (Лабораторная)

- **Цель:** комплексная проверка навыков по модулям 6–8.
- **Содержание:** создать проект-ноутбук: venv → jupyter → ipykernel → данные + визуализация + markdown + магические команды → экспорт → requirements.txt.
- **Принцип «снежного кома»:** pyenv, venv, pip, Jupyter, ядра, типы ячеек, магические команды, экспорт.
- **Файлы:** `README.md`, `solution.md`, `check.sh`.
- **Опирается на:** все юниты модуля 8 и модули 4–7.
