# pyenv + venv + Jupyter Notebook

Практический курс по управлению Python-средой в Linux.

Три инструмента — одна цепочка: **установил нужную версию Python** → **создал изолированное окружение** → **запустил Jupyter с правильным ядром**.

> **Платформа:** Linux Ubuntu-based
> **Формат:** самостоятельное изучение
> **Объём:** 12 модулей, ~80 юнитов, ~4–5 недель (1–2 ч/день)
> **Язык:** русский

---

## Чему научит курс

- Понимать, как устроена Python-среда в Linux (системный Python, PATH, симлинки, shims)
- Управлять несколькими версиями Python на одной машине через **pyenv**
- Уверенно работать с **pip**: устанавливать, удалять, замораживать пакеты
- Создавать и использовать изолированные окружения через **venv**
- Работать в **Jupyter Notebook** и **JupyterLab**: ядра, магические команды, экспорт
- Выстраивать полную рабочую цепочку `pyenv → venv → pip → Jupyter`
- Организовывать проект: структура, `.gitignore`, `requirements.txt`, базовый git
- Диагностировать и устранять типичные проблемы на каждом этапе

## Что внутри

Курс состоит не только из уроков. Каждый модуль включает:

- **Уроки** — теория с примерами и секцией «Частые ошибки»
- **Тренажёры** — пошаговое выполнение с проверкой
- **Лабораторные** — задачи с подсказками и эталонными решениями
- **Лабораторные-диагностики** — находим и исправляем заложенные ошибки
- **Тесты** — проверка знаний с нарастающей сложностью
- **Практика с .ipynb** — готовые ноутбуки с кодом, графиками и заданиями

Практика строится по принципу **«снежного кома»** — каждое задание затрагивает не только новую тему, но и ранее изученные.

## Чего в этом курсе нет

- **Обучения Python** — предполагается, что вы уже знаете язык
- **Windows и macOS** — только Linux Ubuntu-based, без оговорок и сносок
- **conda / miniconda** — упоминается для сравнения, но не изучается
- **poetry / pipenv / PDM** — курс про стандартный venv, а не про менеджеры зависимостей с локфайлами
- **Docker-контейнеров** — изоляция здесь на уровне venv, а не контейнеризации
- **JupyterHub** — многопользовательский сервер, другой класс софта
- **VS Code / PyCharm** — курс работает в терминале и браузере, без привязки к IDE
- **CI/CD и публикации пакетов** — курс про локальную рабочую среду разработчика
- **Data Science и машинного обучения** — Jupyter здесь как инструмент, а не как платформа для анализа данных
- **Углублённого git** — базовые команды даются в Модуле 10, но это не курс по git
