# Программа курса «pyenv + venv + Jupyter Notebook»

> **Статус:** утверждена (Блоки 1–5)
> **Платформа:** Linux Ubuntu-based (Kubuntu)
> **Формат:** самостоятельное изучение, markdown на GitHub
> **Темп:** 1–2 часа в день
> **Объём:** 12 модулей, ~80 юнитов, ~4–5 недель

---

## Цели курса

По окончании курса студент умеет:

1. **Объяснить**, как устроена Python-среда в Linux: системный Python, PATH, симлинки, глобальные пакеты.
2. **Устанавливать и управлять** несколькими версиями Python через pyenv.
3. **Работать с pip** как самостоятельным инструментом: устанавливать, удалять, замораживать пакеты.
4. **Создавать, активировать, удалять** изолированные виртуальные окружения через venv.
5. **Устанавливать и настраивать** Jupyter Notebook и JupyterLab внутри виртуального окружения.
6. **Регистрировать** окружения как ядра Jupyter и управлять ими.
7. **Уверенно работать** в Jupyter Notebook и JupyterLab: ячейки, горячие клавиши, магические команды, экспорт.
8. **Выстраивать полную цепочку**: pyenv install → pyenv local → venv → pip install → jupyter → kernel.
9. **Организовывать проект**: структура, `.gitignore`, `requirements.txt`, базовый git.
10. **Диагностировать и устранять** типичные проблемы на каждом этапе.
11. **Воспроизводить** окружение коллеги по `requirements.txt` + `.python-version`.
