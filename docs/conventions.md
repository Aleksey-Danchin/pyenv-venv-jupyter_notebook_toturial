## README модуля (обложка)

Каждый модуль имеет свой `README.md` в корне директории модуля (например, `course/01-pyenv-basics/README.md`). Это **обложка модуля**, а не учебный юнит.

Содержит:

| Секция | Назначение | Расположение |
|--------|-----------|-------------|
| **Чему вы научитесь** | Навыки, которые студент приобретёт (глаголы в инфинитиве) | Начало |
| **Что будет рассмотрено** | Темы модуля с кратким описанием | Начало |
| **Инструменты и команды** | Команды/утилиты, которые будут изучены в модуле | Начало |
| **Содержание модуля** | Таблица юнитов со ссылками | Середина |
| **Итоги модуля** | Резюме изученного | Конец |
| **Чеклист навыков** | `- [ ]` чекбоксы для самооценки | Конец |
| **Ключевые команды** | Команды, введённые в этом модуле | Конец |

Навигация в обложке модуля: `← Предыдущий модуль | Оглавление | Следующий модуль →` (ссылки на модули, а не юниты).

## Типы учебных единиц

### Урок

Теория с примерами. В конце — секция «Частые ошибки».

Файлы: `README.md`

### Тренажёр (пошаговый)

«Делай как я» — пошаговое выполнение с проверкой результата на каждом шаге.

Файлы: `README.md`, `check.sh`

### Лабораторная работа

Задача с подсказками (спойлер-блоки `<details>`) и эталонным решением.

Файлы: `README.md`, `solution.md`, `check.sh`

### Лабораторная-диагностика

Воспроизводимая поломка → студент ищет и исправляет ошибку.

Файлы: `README.md`, `break.sh`, `solution.md`

### Тест

Вопросы с вариантами ответов. Ответы скрыты в `<details>`.

Файлы: `README.md`

### Практика с .ipynb

Готовый ноутбук с начальным контентом (код, графики, данные) + задания внутри.

Файлы: `README.md`, `*.ipynb`

## Система проверки

1. **Самопроверка** — ожидаемый вывод команды рядом с заданием.
2. **`check.sh`** — bash-скрипт, проверяющий состояние системы.
3. **`solution.md`** — эталонное решение (обязательно для каждой лабораторной).

---

## Навигация

- `course/README.md` — оглавление со ссылками на все модули и юниты.
- Каждый `README.md` юнита содержит:
  - В начале: навигацию `← Назад | Оглавление | Далее →`.
  - Заголовок, тип юнита, ориентировочное время.
  - В конце: дублирование навигации.

## Терминология

Курс не боится профессиональной терминологии.

| Момент | Действие |
|--------|----------|
| Первое появление термина | Определение прямо в тексте + запись в `course/references/glossary.md` |
| Последующие использования | Термин без пояснений, со сноской на глоссарий |
| Никогда | Повторно объяснять уже определённый термин |

Глоссарий: `course/references/glossary.md` — таблица `Термин | Определение | Где впервые встречается`.

## Медиаданные

| Правило | Описание |
|---------|----------|
| Текст > скриншот | Для терминала — текстовый вывод в блоке ` ```bash ``` ` |
| Скриншоты | Только для GUI (Jupyter в браузере и т.п.) |
| GIF | Для последовательностей GUI-действий |
| Хранение | В директории юнита рядом с `README.md` |

Утилиты: `flameshot` (скриншоты), `peek` (GIF), `ffmpeg` (конвертация).

## Pre-made Jupyter Notebooks

Используются в Модуле 8 (Jupyter: практикум) и, возможно, в Модуле 11 (Интеграция).

- Готовые `.ipynb` файлы с начальным контентом: Python-код, графики (matplotlib), данные.
- Демонстрируют мощь Jupyter, а не заставляют начинать с чистого листа.
- Имена: `practice-описание.ipynb` (например, `practice-matplotlib-basics.ipynb`).
- Данные — встроенные (маленькие списки/словари), без внешних CSV.
- Используются стандартные библиотеки + matplotlib.

## Команды терминала

При встрече новой терминальной команды:

1. Справка в 1–2 предложения прямо в тексте урока.
2. Запись в `course/references/terminal-commands.md`.

Это побочный материал — знания по терминалу не тестируются.

---

## Практика: принцип «снежного кома»

Тесты и лабораторные размещаются после каждых 2–3 уроков и включают:
- Темы только что изученных уроков.
- Ранее изученные темы этого же модуля.

Не создаётся отдельный тест/лабораторная на каждый урок.

## Сравнения с альтернативами

Краткие вставки внутри основных уроков (не отдельные юниты):
- pyenv vs `apt install python3.x`, conda, asdf
- venv vs virtualenv, conda environments, poetry/pipenv
- pip vs conda, pipx
- Jupyter Notebook vs JupyterLab vs VS Code Notebooks

## Git в курсе

Модуль 10 (Проектная практика) включает базовые команды git:
- `git init`, `git add`, `git commit`, `git push`
- Создание репозитория на GitHub
- `.gitignore` для Python-проектов

**Это не курс по git.** Базовые команды даются для контекста — достаточно для публикации проекта. В курсе явно указывается это ограничение.
