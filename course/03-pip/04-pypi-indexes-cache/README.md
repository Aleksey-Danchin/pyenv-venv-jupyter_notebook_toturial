# Откуда берутся пакеты: PyPI, индексы, кеш

> **Модуль 3 · Урок 4** | Время: ~15 мин

## PyPI как индекс по умолчанию

По умолчанию pip обращается к **PyPI** (https://pypi.org) — официальному репозиторию Python-пакетов. Когда вы выполняете `pip install requests`, pip:

1. Запрашивает метаданные пакета с PyPI.
2. Скачивает архив (wheel или sdist).
3. Устанавливает пакет в site-packages.

## Индекс пакетов

**Индекс пакетов**[^глоссарий]([Глоссарий](../../references/glossary.md)) — сервер, который предоставляет метаданные и файлы пакетов по стандартному протоколу (PEP 503). PyPI — один из таких индексов.

Когда PyPI недоступен (внутренняя сеть, зеркало, приватный репозиторий), можно указать другой индекс:

```bash
python3 -m pip install --index-url https://pypi.example.com/simple/ requests
```

Или добавить **дополнительный** индекс (pip будет искать в обоих):

```bash
python3 -m pip install --extra-index-url https://internal-pypi.company.com/simple/ requests
```

## Конфигурация pip

Команда `pip config` позволяет управлять настройками pip. Посмотреть текущую конфигурацию:

```bash
python3 -m pip config list
```

Установить индекс по умолчанию (для текущего пользователя):

```bash
python3 -m pip config set global.index-url https://pypi.org/simple
```

Конфигурация хранится в `~/.config/pip/pip.conf` (Linux) или `~/.pip/pip.conf`.

## Кеш pip

Чтобы ускорить повторные установки, pip **кеширует** скачанные пакеты. При следующей установке того же пакета той же версии pip возьмёт файл из кеша, не обращаясь к сети.

Путь к кешу (Linux):

```
~/.cache/pip/
```

Просмотр информации о кеше:

```bash
python3 -m pip cache info
```

Очистка кеша:

```bash
python3 -m pip cache purge
```

Установка **без** использования кеша (всегда скачивать заново):

```bash
python3 -m pip install --no-cache-dir requests
```

Флаг `--no-cache-dir` полезен при диагностике проблем с повреждённым кешем.

## Частые ошибки

### Ошибка 1 — Не знать, куда pip идёт за пакетами

Если установка «зависла» или падает с ошибкой сети, проверьте: `pip config list` покажет настроенный индекс. По умолчанию это PyPI. В корпоративных сетях часто используют зеркало — уточните у администратора.

### Ошибка 2 — Проблемы при недоступности PyPI

При блокировке или нестабильном доступе к PyPI используйте зеркало (например, в Китае, на изолированных серверах) или внутренний индекс. Настройте `index-url` через `pip config set`.

### Ошибка 3 — Повреждённый кеш

Если pip выдаёт странные ошибки при установке известного пакета, попробуйте `pip cache purge` и повторите установку. Иногда кеш повреждается.
