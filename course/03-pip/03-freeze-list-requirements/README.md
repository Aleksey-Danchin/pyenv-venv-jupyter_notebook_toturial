# pip freeze, pip list и requirements.txt

> **Модуль 3 · Урок 3** | Время: ~15 мин

## Просмотр установленных пакетов

Команда `pip list` выводит все установленные пакеты в «человекочитаемом» формате:

```bash
python3 -m pip list
```

```
Package    Version
---------- -------
pip        24.0
requests   2.31.0
urllib3    2.1.0
```

Команда `pip freeze` выводит пакеты в формате, пригодном для **requirements.txt**:

```bash
python3 -m pip freeze
```

```
pip==24.0
requests==2.31.0
urllib3==2.1.0
```

## Разница между list и freeze

| Команда | Назначение |
|---------|------------|
| `pip list` | Информационный вывод для человека. Показывает пакеты и версии. |
| `pip freeze` | Вывод для машины. Строки вида `package==version`, готовые для копирования в requirements.txt. |

`pip freeze` по умолчанию **включает pip** и все зависимости. Для проекта часто нужны только «прямые» зависимости — те, что вы устанавливали сами. В продвинутых сценариях для этого используют `pip-tools` или `pip freeze` с последующей ручной вычисткой.

## Что такое requirements.txt

**requirements.txt**[^глоссарий]([Глоссарий](../../references/glossary.md)) — текстовый файл со списком пакетов и их версий. Обычно хранится в корне проекта и используется для воспроизведения окружения.

Создать requirements.txt из текущего окружения:

```bash
python3 -m pip freeze > requirements.txt
```

Содержимое файла:

```
pip==24.0
requests==2.31.0
urllib3==2.1.0
```

## Установка из requirements.txt

Чтобы установить все пакеты из файла:

```bash
python3 -m pip install -r requirements.txt
```

Опция `-r` (или `--requirement`) указывает pip прочитать зависимости из файла.

## Воспроизведение окружения

Типичный рабочий процесс:

1. Разработчик устанавливает нужные пакеты в своём окружении.
2. Сохраняет их список: `pip freeze > requirements.txt`.
3. Коммитит `requirements.txt` в репозиторий.
4. Коллега или CI клонирует репозиторий и выполняет `pip install -r requirements.txt` — получает такое же окружение.

Файл `requirements.txt` — стандарт де-факто для фиксации зависимостей Python-проекта.

## Частые ошибки

### Ошибка 1 — Путать list и freeze

`pip list` — для просмотра. `pip freeze` — для сохранения в файл и воспроизведения. Использование `pip list` для формирования requirements.txt даст неверный формат.

### Ошибка 2 — Забывать freeze при коммите проекта

Если вы добавили зависимость (`pip install new-package`) и не обновили `requirements.txt`, коллега или вы на другой машине не сможете воспроизвести окружение. Привыкайте после каждой установки выполнять `pip freeze > requirements.txt` и коммитить изменения.

### Ошибка 3 — Включать в requirements.txt пакеты из системного окружения

Убедитесь, что `pip freeze` выполняется в **нужном** окружении (например, внутри активированного venv). Иначе в файл попадут пакеты из глобального окружения, что может сломать воспроизводимость.
