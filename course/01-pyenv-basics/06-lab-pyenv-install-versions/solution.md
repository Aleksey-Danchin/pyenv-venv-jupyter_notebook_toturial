# Эталонное решение: установка и просмотр версий Python

## Шаги решения

### 1. Установка Python 3.11.7

```bash
pyenv install 3.11.7
```

Дождитесь завершения компиляции (1–5 минут).

### 2. Проверка установки

```bash
pyenv versions
```

Версия 3.11.7 должна появиться в списке.

### 3. Поиск бинарника

```bash
ls ~/.pyenv/versions/3.11.7/bin/python3.11
```

Полный путь: `~/.pyenv/versions/3.11.7/bin/python3.11`.

Альтернативный способ — из модуля 0 (работает, когда версия активна):

```bash
pyenv shell 3.11.7
which python3
```

### 4. Текущая активная версия

```bash
pyenv version
```

Вывод покажет активную версию и источник, например:

```
3.12.0 (set by /home/<user>/.pyenv/version)
```

Источник `set by` указывает файл или переменную окружения, из которых pyenv определил версию.

### 5. Последний стабильный релиз 3.12.x

```bash
pyenv install --list | grep "^\s*3\.12\." | grep -v "dev\|a\|b\|rc" | tail -1
```

## Ожидаемый результат

```bash
pyenv versions
```

```
  system
* 3.12.0 (set by /home/<user>/.pyenv/version)
  3.11.7
```

Версия 3.11.7 присутствует в списке установленных.
