# Лабораторная: установка и просмотр версий Python

> **Модуль 1 · Лабораторная** | Время: ~10 мин

## Задание

Выполните следующие задачи:

1. Установите через pyenv версию **Python 3.11.7** (если у вас уже установлена 3.11.x — выберите другой патч-релиз из ветки 3.11).
2. Убедитесь, что установленная версия появилась в списке `pyenv versions`.
3. Найдите, где физически расположен бинарник `python3.11` установленной версии (полный путь).
4. Определите, какая версия Python сейчас **активна** по мнению pyenv, и объясните, откуда pyenv взял эту информацию (источник: `set by ...`).
5. Используя `pyenv install --list`, найдите последний стабильный релиз ветки 3.12.x (без альфа, бета, rc).

## Требования

- Версия Python 3.11.7 (или аналогичная) установлена и видна в `pyenv versions`.
- Вы можете показать полный путь к бинарнику установленной версии.
- Вы можете назвать текущую активную версию и источник, из которого pyenv её определил.
- Вы нашли номер последнего стабильного релиза 3.12.x.

## Подсказка 1

Показать подсказку

Для установки версии используйте `pyenv install <version>`. Для просмотра установленных версий — `pyenv versions`. Для поиска бинарника вспомните, где pyenv хранит установленные версии (урок 03).



## Подсказка 2

Показать подсказку

Бинарники установленных версий находятся в `~/.pyenv/versions/<version>/bin/`. Текущую активную версию показывает `pyenv version` — обратите внимание на текст в скобках `(set by ...)`. Для фильтрации списка используйте `grep`.



## Подсказка 3

Показать подсказку

Полный путь к бинарнику: `~/.pyenv/versions/3.11.7/bin/python3.11`. Для поиска последнего стабильного 3.12.x выполните:

```bash
pyenv install --list | grep "^\s*3\.12\." | grep -v "dev\|a\|b\|rc" | tail -1
```



## Самопроверка

После выполнения проверьте:

```bash
pyenv versions | grep "3.11"
```

**Ожидаемый результат:**

```
  3.11.7
```

Версия 3.11.7 (или ваш вариант) присутствует в списке.

```bash
ls ~/.pyenv/versions/3.11.7/bin/python3.11
```

**Ожидаемый результат:**

```
/home/<user>/.pyenv/versions/3.11.7/bin/python3.11
```

Файл существует.

Также запустите скрипт проверки:

```bash
bash check.sh
```
