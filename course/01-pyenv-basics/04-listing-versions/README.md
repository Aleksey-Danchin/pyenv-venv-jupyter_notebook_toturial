# Просмотр доступных и установленных версий

> **Модуль 1 · Урок 4** | Время: ~5 мин

## Какие версии можно установить

Команда `pyenv install --list` выводит все версии Python, которые pyenv умеет устанавливать:

```bash
pyenv install --list
```

```
Available versions:
  2.1.3
  2.2.3
  ...
  3.11.7
  3.12.0
  3.12.1
  3.13.0a3
  ...
  anaconda3-2023.09
  pypy3.10-7.3.13
  ...
```

Список длинный — сотни записей. В нём не только CPython, но и PyPy, Anaconda, MicroPython и другие реализации.

### Фильтрация списка

Чтобы найти нужную версию, используйте `grep`:

```bash
pyenv install --list | grep "^\s*3\.12"
```

```
  3.12.0
  3.12.1
  3.12.2
  3.12.3
  ...
```

Так вы увидите только патч-релизы ветки 3.12.

Для поиска только стабильных релизов CPython (без альфа, бета, PyPy и т.д.):

```bash
pyenv install --list | grep "^\s*3\." | grep -v "dev\|a\|b\|rc"
```

## Какие версии уже установлены

### `pyenv versions`

Показывает все версии Python, установленные через pyenv:

```bash
pyenv versions
```

```
  system
* 3.12.0 (set by /home/<user>/.pyenv/version)
  3.11.7
```

Что здесь важно:

- `**system**` — системный Python (`/usr/bin/python3`). pyenv всегда знает о нём.
- **Звёздочка `*`** — отмечает текущую активную версию.
- `**(set by ...)**` — показывает, откуда pyenv взял информацию об активной версии.

### `pyenv version`

Показывает только текущую активную версию (без полного списка):

```bash
pyenv version
```

```
3.12.0 (set by /home/<user>/.pyenv/version)
```

## `pyenv versions` vs `pyenv version`


| Команда          | Что показывает                              | Когда использовать                          |
| ---------------- | ------------------------------------------- | ------------------------------------------- |
| `pyenv versions` | Все установленные версии + отметка активной | Хотите увидеть полную картину               |
| `pyenv version`  | Только текущую активную версию              | Хотите быстро проверить, что сейчас активно |


Обратите внимание на разницу в одну букву `s` — это частый источник путаницы.

## Источник активной версии

В выводе `pyenv version` указано `(set by ...)`. Это подсказка, откуда pyenv определил активную версию:


| Источник                                    | Значение                                       |
| ------------------------------------------- | ---------------------------------------------- |
| `set by /home/<user>/.pyenv/version`        | Глобальная настройка (файл `~/.pyenv/version`) |
| `set by /path/to/project/.python-version`   | Локальная настройка проекта                    |
| `set by PYENV_VERSION environment variable` | Переменная окружения (текущая сессия)          |


Подробнее о переключении версий и приоритетах — в модуле 2.

## Где хранятся установленные версии

Все версии расположены в `~/.pyenv/versions/`:

```bash
ls ~/.pyenv/versions/
```

```
3.11.7  3.12.0
```

Каждая директория — независимая установка Python. Удаление директории равносильно удалению версии (хотя для этого есть команда `pyenv uninstall`).

## Частые ошибки

### Ошибка 1 — Путаница `pyenv version` и `pyenv versions`

`pyenv version` (без `s`) показывает только активную версию. `pyenv versions` (с `s`) — все установленные. Если вы установили Python, но не видите его в выводе — проверьте, что используете `versions` (с `s`).

### Ошибка 2 — Поиск версии в огромном списке без фильтрации

`pyenv install --list` выводит сотни строк. Не прокручивайте вручную — используйте `grep` для фильтрации (примеры выше).

### Ошибка 3 — Ожидание обновлённого списка без обновления pyenv

Список доступных версий зашит в pyenv. Если вышла новая версия Python, но `pyenv install --list` её не показывает, нужно обновить сам pyenv:

```bash
cd ~/.pyenv && git pull
```

После обновления новые версии появятся в списке.
