# Установка версии Python через pyenv

> **Модуль 1 · Урок 3** | Время: ~5 мин

## Зачем устанавливать Python через pyenv

Системный Python привязан к версии, которую выбрал дистрибутив. Если вашему проекту нужна другая версия — например, 3.11 для совместимости с продакшеном или 3.13 для тестирования новых возможностей — pyenv позволяет установить её за одну команду.

## Команда `pyenv install`

Основная команда для установки:

```bash
pyenv install 3.12.0
```

pyenv скачивает исходники указанной версии CPython и компилирует их локально. Процесс занимает от 1 до 5 минут в зависимости от мощности компьютера.

Во время компиляции вы увидите:

```
Downloading Python-3.12.0.tar.xz...
-> https://www.python.org/ftp/python/3.12.0/Python-3.12.0.tar.xz
Installing Python-3.12.0...
Installed Python-3.12.0 to /home/<user>/.pyenv/versions/3.12.0
```

## Что происходит за сценой

Когда вы выполняете `pyenv install 3.12.0`, pyenv:

1. **Скачивает** архив с исходниками CPython с python.org.
2. **Распаковывает** его во временную директорию.
3. **Компилирует** Python из исходников (вот зачем нужны зависимости сборки из предыдущего тренажёра).
4. **Устанавливает** скомпилированный Python в `~/.pyenv/versions/3.12.0/`.
5. **Обновляет shims** — запускает `pyenv rehash`, чтобы новые бинарники стали доступны.

```
~/.pyenv/versions/
├── 3.12.0/
│   ├── bin/
│   │   ├── python
│   │   ├── python3
│   │   ├── python3.12
│   │   └── pip3.12
│   ├── lib/
│   └── ...
```

Каждая версия — полностью самостоятельная установка Python со своим `bin/`, `lib/` и `site-packages/`.

## Версии, которые можно установить

pyenv поддерживает не только стабильные релизы CPython. Можно установить:

- Конкретный патч-релиз: `pyenv install 3.11.7`
- Предрелизную версию: `pyenv install 3.13.0a3`
- Другие реализации: `pyenv install pypy3.10-7.3.13` (PyPy), `pyenv install anaconda3-2023.09` (Anaconda)

Полный список доступных версий — в следующем уроке.

## Время компиляции

Компиляция Python — ресурсоёмкая операция. Примерные ориентиры:


| Машина                        | Время      |
| ----------------------------- | ---------- |
| Современный ноутбук (4+ ядер) | 1–3 минуты |
| Слабый или виртуальный сервер | 5–10 минут |


Во время компиляции терминал может выглядеть «зависшим» — это нормально. Не прерывайте процесс. Если компиляция идёт слишком долго, проверьте, что система не перегружена другими задачами.

## Установка нескольких версий

Можно установить любое количество версий — они не мешают друг другу:

```bash
pyenv install 3.11.7
pyenv install 3.12.0
pyenv install 3.13.0
```

Каждая версия занимает отдельную директорию в `~/.pyenv/versions/` и полностью изолирована.

## Частые ошибки

### Ошибка 1 — Не установлены зависимости сборки

Самая частая проблема — компиляция падает из-за отсутствия системных библиотек:

```
ERROR: The Python ssl extension was not compiled. Missing the OpenSSL lib?
```

**Решение:** установите зависимости сборки (шаг 1 из тренажёра). Подробная диагностика — в юните 07 этого модуля.

### Ошибка 2 — Прерывание компиляции

Если нажать `Ctrl+C` во время `pyenv install`, установка прервётся, и версия не появится в списке. Это безопасно — повторите команду заново. pyenv скачает исходники повторно (или использует кеш) и начнёт компиляцию с начала.

### Ошибка 3 — Опечатка в номере версии

```bash
pyenv install 3.120
```

```
python-build: definition not found: 3.120
```

Номер версии должен быть точным. Проверить доступные версии можно командой `pyenv install --list` (следующий урок).
