# Лабораторная-диагностика: pyenv install не компилирует Python

> **Модуль 1 · Диагностика** | Время: ~10 мин

## Сценарий

Коллега настроил pyenv на рабочей машине. Раньше всё работало, но после «чистки системы» команда `pyenv install` перестала завершаться успешно — компиляция Python падает с ошибкой.

Ваша задача — воспроизвести проблему, найти причину и исправить.

## Воспроизведение проблемы

Запустите скрипт, создающий «сломанное» состояние:

```bash
bash break.sh
```

После этого попробуйте установить версию Python:

```bash
pyenv install 3.11.7
```

## Симптомы

Компиляция завершается с ошибкой. В выводе вы увидите сообщения вроде:

```
ERROR: The Python ssl extension was not compiled. Missing the OpenSSL lib?
```

или:

```
configure: error: OpenSSL is not installed.
```

Python может даже частично скомпилироваться, но pyenv сообщит об ошибке и не добавит версию в список.

## Задание

1. Изучите вывод ошибки `pyenv install`.
2. Определите, какого компонента не хватает.
3. Исправьте проблему.
4. Повторите `pyenv install` и убедитесь, что компиляция завершилась успешно.

## Подсказка 1

Показать подсказку

Обратите внимание на текст ошибки — он указывает на конкретную библиотеку. Вспомните, какие системные пакеты нужны для компиляции Python (тренажёр 02).



## Подсказка 2

Показать подсказку

Проблема связана с заголовочными файлами OpenSSL. Проверьте, установлен ли пакет `libssl-dev`:

```bash
dpkg -l | grep libssl-dev
```

Если строка пустая или пакет не установлен — в этом причина.



## Подсказка 3

Показать подсказку

Установите недостающий пакет:

```bash
sudo apt install -y libssl-dev
```

После этого повторите установку Python:

```bash
pyenv install 3.11.7
```



## Самопроверка

```bash
pyenv versions | grep "3.11.7"
```

**Ожидаемый результат:**

```
  3.11.7
```

Версия успешно установлена и присутствует в списке.
