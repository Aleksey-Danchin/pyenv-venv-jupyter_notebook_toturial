# Эталонное решение: pyenv install не компилирует Python

## Диагностика

### 1. Анализ ошибки

При попытке `pyenv install 3.11.7` в выводе ошибки фигурирует:

```
ERROR: The Python ssl extension was not compiled. Missing the OpenSSL lib?
```

Это означает, что компилятор не нашёл заголовочные файлы OpenSSL.

### 2. Проверка пакета

```bash
dpkg -l | grep libssl-dev
```

Вывод пустой — пакет `libssl-dev` не установлен.

## Шаги решения

### 1. Установка недостающего пакета

```bash
sudo apt install -y libssl-dev
```

### 2. Повторная установка Python

```bash
pyenv install 3.11.7
```

### 3. Проверка

```bash
pyenv versions | grep "3.11.7"
```

## Ожидаемый результат

```
  3.11.7
```

Версия успешно установлена.

## Пояснение

При компиляции Python из исходников собираются модули стандартной библиотеки, в том числе `ssl`. Этот модуль зависит от заголовочных файлов OpenSSL (`libssl-dev`). Без них компиляция модуля `ssl` невозможна, и pyenv сообщает об ошибке.

Полный список зависимостей сборки — в тренажёре «Установка pyenv» (юнит 02).
