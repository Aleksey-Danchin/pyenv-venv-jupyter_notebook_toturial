# Модуль 1. pyenv: установка и основы

> **Время:** ~2 дня (при темпе 1–2 часа в день)

## Чему вы научитесь

- Объяснять, какую проблему решает pyenv и чем он отличается от системного Python.
- Устанавливать pyenv и настраивать shell для работы с ним.
- Устанавливать произвольные версии Python через pyenv.
- Просматривать доступные и установленные версии Python.
- Диагностировать ошибки компиляции при установке Python.

## Что будет рассмотрено

| Тема | Описание |
|------|----------|
| Назначение pyenv | Зачем нужен менеджер версий Python и как он работает через shims. |
| Установка pyenv | Зависимости сборки, установка через curl, настройка `.bashrc`. |
| Установка Python | Компиляция и установка конкретной версии Python через `pyenv install`. |
| Просмотр версий | Команды для просмотра доступных и установленных версий. |
| Диагностика | Что делать, когда `pyenv install` не может скомпилировать Python. |

## Инструменты и команды

| Команда / инструмент | Назначение |
|---------------------|-----------|
| `pyenv --version` | Проверить, что pyenv установлен. |
| `pyenv install <version>` | Скомпилировать и установить версию Python. |
| `pyenv install --list` | Показать все доступные для установки версии. |
| `pyenv versions` | Показать установленные версии Python. |
| `pyenv version` | Показать текущую активную версию Python. |

## Итоги модуля

### Что вы изучили

- Зачем нужен pyenv и как он отличается от `apt install python3.x`.
- Как установить pyenv и подготовить систему (зависимости сборки).
- Как скомпилировать и установить любую версию CPython через `pyenv install`.
- Как просматривать доступные и установленные версии.
- Как диагностировать ошибки компиляции при отсутствии зависимостей.

### Чеклист навыков

Отметьте то, что вы уверенно можете сделать:

- [ ] Объяснить, зачем нужен pyenv и какую проблему он решает.
- [ ] Установить pyenv с нуля на чистой системе.
- [ ] Установить конкретную версию Python через `pyenv install`.
- [ ] Найти нужную версию в списке `pyenv install --list`.
- [ ] Объяснить разницу между `pyenv version` и `pyenv versions`.
- [ ] Диагностировать ошибку компиляции из-за отсутствия зависимостей сборки.

### Ключевые команды

```bash
pyenv --version             # проверить установку pyenv
pyenv install --list        # список доступных версий
pyenv install 3.12.0        # установить конкретную версию
pyenv versions              # список установленных версий
pyenv version               # текущая активная версия
```
