# Практика: магические команды в реальном сценарии

> **Модуль 8 · Практика 03** | Время: ~25 мин

## Цель

Применить магические команды Jupyter в практической задаче: замерить время выполнения, проверить версии пакетов, выполнить shell-команду, вывести переменные окружения.

## Что нужно

- Активированное venv с Jupyter (модули 4–7).
- Готовый ноутбук `practice-magic-commands.ipynb` — откройте его в Jupyter.

## Как работать

1. Запустите Jupyter: `jupyter notebook`
2. Откройте `practice-magic-commands.ipynb`
3. Выполняйте ячейки по порядку
4. Выполните все задания в ячейках — каждая требует применить магическую команду

## Самопроверка

- Использованы `%timeit`, `!pip`, `%env`, `%run` (или аналог)
- Результаты команд видны в выводе ячеек
- Все задания выполнены согласно инструкциям
