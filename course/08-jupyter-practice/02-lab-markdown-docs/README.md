# Практика: Markdown-документация внутри ноутбука

> **Модуль 8 · Практика 02** | Время: ~20 мин

## Цель

Освоить оформление ноутбука с помощью Markdown: заголовки, списки, форматирование, описание шагов. Документированный ноутбук легче понять и воспроизвести.

## Что нужно

- Активированное venv с Jupyter и matplotlib (как в практике 01).
- Готовый ноутбук `practice-markdown-docs.ipynb` — откройте его в Jupyter.

## Как работать

1. Запустите Jupyter: `jupyter notebook`
2. Откройте `practice-markdown-docs.ipynb`
3. Выполните ячейки с кодом (Shift+Enter)
4. Заполните пустые Markdown-ячейки согласно заданиям
5. Выполните Markdown-ячейки, чтобы увидеть результат рендеринга

## Самопроверка

- Заголовки уровней 1–3 отображаются корректно
- Списки (нумерованные и маркированные) отформатированы
- В коде есть пояснения: что делает блок, какие данные обрабатываются
- Выполнены все три задания из ноутбука
