# Практика: работа с данными и визуализацией (matplotlib)

> **Модуль 8 · Практика 01** | Время: ~25 мин

## Цель

Набить руку в работе с данными и построении графиков в Jupyter: использовать готовый ноутбук с примерами и выполнить задания по визуализации.

## Предусловия

- Вы прошли модули 6 и 7: Jupyter запускаете из venv, работаете с нужным ядром.
- У вас есть активированное виртуальное окружение с Jupyter и matplotlib.

## Задание

Откройте ноутбук `practice-data-visualization.ipynb` в Jupyter (File → Open или перетащите файл в браузер).

В ноутбуке:

1. **Контекст** — уже есть данные (список значений) и базовый график matplotlib.
2. **Задания** — отмечены как `## Задание N`. Выполните каждое задание в соответствующих пустых ячейках.
3. **Самопроверка** — после выполнения всех заданий запустите все ячейки (Cell → Run All) и убедитесь, что графики отображаются без ошибок.

## Подсказка 1

<details><summary>Показать подсказку</summary>

Используйте `plt` (pyplot) для построения графиков. Методы `plt.plot()`, `plt.xlabel()`, `plt.title()` и т.п. — см. урок по matplotlib или документацию.

</details>

## Подсказка 2

<details><summary>Показать подсказку</summary>

`%matplotlib inline` в начале ноутбука гарантирует отображение графиков прямо в ячейке вывода. Если график не появляется — выполните ячейку с этой командой первой.

</details>

## Подсказка 3

<details><summary>Показать подсказку</summary>

Для добавления легенды: `plt.legend()`. Для показа графика: `plt.show()`. В Jupyter с `%matplotlib inline` вызов `show()` часто не обязателен — график выводится автоматически после выполнения ячейки.

</details>

## Самопроверка

- Все ячейки выполняются без ошибок.
- Графики отображаются под соответствующими ячейками.
- Вы выполнили все задания из ноутбука.
