# Модуль 8. Jupyter: практикум

> **Время:** ~2 дня (при темпе 1–2 часа в день)

## Чему вы научитесь

- Работать с данными и строить графики в Jupyter с помощью matplotlib
- Оформлять ноутбуки с помощью Markdown-документации
- Применять магические команды в реальных сценариях
- Экспортировать ноутбуки и воспроизводить их на другой машине
- Выполнять комплексную работу: от venv до готового ноутбука с экспортом

## Что будет рассмотрено

| Тема | Описание |
|------|----------|
| Данные и визуализация | Pre-made ноутбук с matplotlib: данные, графики, задания |
| Markdown в ноутбуке | Оформление: заголовки, списки, описание шагов |
| Магические команды | %timeit, %run, !pip, %env в практическом сценарии |
| Экспорт и воспроизведение | nbconvert, передача проекта коллеге, воспроизведение окружения |
| Итоговая лабораторная | Полный цикл: venv → Jupyter → ядро → данные → визуализация → экспорт |

## Инструменты и команды

| Команда / инструмент | Назначение |
|---------------------|-----------|
| `jupyter nbconvert --to <формат> <файл>` | Экспорт ноутбука в HTML, PDF, .py |
| `pip freeze > requirements.txt` | Фиксация зависимостей для воспроизведения |
| `pip install -r requirements.txt` | Воспроизведение окружения по requirements |
| `jupyter notebook` | Запуск Jupyter (для воспроизведения проекта) |

## Итоги модуля

### Что вы изучили

- Практика с pre-made ноутбуками: данные (списки, словари), matplotlib, Markdown, магические команды.
- Экспорт ноутбука: `jupyter nbconvert --to html/pdf/script`; выбор формата под задачу.
- Воспроизведение проекта: requirements.txt + .ipynb, создание venv, установка зависимостей, запуск Jupyter.
- Полный цикл: pyenv → venv → pip → Jupyter → ipykernel → ноутбук → экспорт.

### Чеклист навыков

Отметьте то, что вы уверенно можете сделать:

- [ ] Построить график в Jupyter с помощью matplotlib (данные из списка/словаря)
- [ ] Добавить Markdown-ячейки с заголовками, списками и описанием шагов
- [ ] Использовать магические команды (%timeit, !pip, %env) в практической задаче
- [ ] Экспортировать ноутбук в HTML и .py
- [ ] Передать проект коллеге: .ipynb + requirements.txt + .python-version
- [ ] Воспроизвести чужой проект: venv, pip install -r, jupyter

### Ключевые команды

```bash
jupyter nbconvert --to html notebook.ipynb
jupyter nbconvert --to script notebook.ipynb
pip freeze > requirements.txt
pip install -r requirements.txt
jupyter notebook
```
