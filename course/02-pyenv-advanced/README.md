# Модуль 2. pyenv: управление версиями

> **Время:** ~3 дня (при темпе 1–2 часа в день)

## Чему вы научитесь

- Переключать глобальную версию Python через `pyenv global`.
- Привязывать версию Python к конкретному проекту через `pyenv local`.
- Временно менять версию Python в текущей сессии терминала через `pyenv shell`.
- Объяснять приоритет версий: shell → local → global → system.
- Удалять ненужные версии Python из pyenv.
- Обновлять и при необходимости полностью деинсталлировать pyenv.
- Диагностировать проблему «python не найден после установки pyenv».

## Что будет рассмотрено

| Тема | Описание |
|------|----------|
| Глобальная версия | Команда `pyenv global` и файл `~/.pyenv/version`. |
| Локальная версия | Команда `pyenv local` и файл `.python-version` в директории проекта. |
| Сессионная версия | Команда `pyenv shell` и переменная окружения `PYENV_VERSION`. |
| Приоритет версий | Цепочка разрешения: shell > local > global > system. |
| Удаление версий | Команда `pyenv uninstall` и ручное удаление. |
| Обновление и деинсталляция | Обновление pyenv через git, полное удаление pyenv из системы. |
| Диагностика | Типичная проблема: `python` не найден после установки pyenv. |

## Инструменты и команды

| Команда / инструмент | Назначение |
|---------------------|-----------|
| `pyenv global <version>` | Установить глобальную версию Python. |
| `pyenv local <version>` | Привязать версию Python к текущей директории. |
| `pyenv shell <version>` | Установить версию Python для текущей сессии shell. |
| `pyenv shell --unset` | Сбросить сессионную версию. |
| `pyenv uninstall <version>` | Удалить установленную версию Python. |

## Итоги модуля

### Что вы изучили

- Три уровня переключения версий Python: глобальный, локальный (для проекта) и сессионный.
- Цепочку приоритетов pyenv: shell > local > global > system.
- Как привязать версию Python к проекту через `.python-version`.
- Как удалять ненужные версии Python из pyenv.
- Как обновлять pyenv и как полностью деинсталлировать его при необходимости.
- Как диагностировать проблему «python не найден» после установки pyenv.

### Чеклист навыков

Отметьте то, что вы уверенно можете сделать:

- [ ] Установить глобальную версию Python через `pyenv global`.
- [ ] Привязать версию Python к проекту через `pyenv local`.
- [ ] Временно переключить версию в текущей сессии через `pyenv shell`.
- [ ] Объяснить порядок приоритетов: shell > local > global > system.
- [ ] Определить, откуда взялась текущая версия Python (через `pyenv version`).
- [ ] Удалить ненужную версию Python через `pyenv uninstall`.
- [ ] Обновить pyenv до последней версии.
- [ ] Диагностировать и исправить проблему «python не найден после установки pyenv».

### Ключевые команды

```bash
pyenv global 3.12.0        # установить глобальную версию
pyenv global               # показать текущую глобальную версию
pyenv local 3.11.7         # привязать версию к директории
pyenv local --unset        # удалить .python-version
pyenv shell 3.13.0         # установить версию для сессии
pyenv shell --unset        # сбросить сессионную версию
pyenv uninstall 3.11.7     # удалить версию Python
cd ~/.pyenv && git pull     # обновить pyenv
```
