# Удаление версии Python через pyenv

> **Модуль 2 · Урок 5** | Время: ~15 мин

## Зачем удалять версии

Каждая установленная через pyenv версия Python занимает на диске 50–200 МБ (в `~/.pyenv/versions/`). Со временем накапливаются версии, которые больше не нужны: устаревшие, экспериментальные, установленные для разового теста.

Удаление ненужных версий освобождает место и упрощает вывод `pyenv versions`.

## Команда `pyenv uninstall`

Основной способ удаления:

```bash
pyenv uninstall 3.11.7
```

pyenv запросит подтверждение:

```
pyenv: remove /home/user/.pyenv/versions/3.11.7? (y/n) y
```

После подтверждения версия удаляется.

Чтобы пропустить подтверждение (полезно в скриптах):

```bash
pyenv uninstall -f 3.11.7
```

## Альтернативный способ: ручное удаление

Версии Python хранятся как обычные директории в `~/.pyenv/versions/`:

```bash
ls ~/.pyenv/versions/
```

```
3.11.7  3.12.0  3.13.0
```

Удалить версию можно и вручную:

```bash
rm -rf ~/.pyenv/versions/3.11.7
```

Результат идентичен `pyenv uninstall`. После удаления рекомендуется пересоздать shims[^глоссарий]:

```bash
pyenv rehash
```

[^глоссарий]: [Глоссарий](../../references/glossary.md)

## Что происходит после удаления

### Если удалённая версия была глобальной

```bash
pyenv global 3.11.7
pyenv uninstall 3.11.7
python --version
```

```
pyenv: version '3.11.7' is not installed (set by /home/user/.pyenv/version)
```

Файл `~/.pyenv/version` по-прежнему содержит `3.11.7`, но самой версии уже нет. Нужно обновить глобальную настройку:

```bash
pyenv global 3.12.0
```

### Если удалённая версия была локальной

Аналогично: файл `.python-version` остаётся, но pyenv выдаёт ошибку. Нужно обновить или удалить файл:

```bash
pyenv local 3.12.0
# или
pyenv local --unset
```

### Если удалённая версия не была ни global, ни local

Ничего не происходит — версия просто исчезает из `pyenv versions`.

## Проверка после удаления

```bash
pyenv versions
```

Убедитесь, что удалённой версии нет в списке, и что `pyenv version` показывает корректную активную версию без ошибок.

## Частые ошибки

### Ошибка 1 — Удалить версию, привязанную к `.python-version`

Если в каком-то проекте есть `.python-version` с удалённой версией, при переходе в эту директорию pyenv выдаст ошибку. Перед удалением проверьте, не используется ли версия в проектах:

```bash
grep -r "3.11.7" ~/projects/*/.python-version 2>/dev/null
```

### Ошибка 2 — Не обновить global после удаления

Если удалённая версия была глобальной, каждый вызов `python` будет заканчиваться ошибкой. Сразу после удаления назначьте другую глобальную версию:

```bash
pyenv global 3.12.0
```

### Ошибка 3 — Пытаться удалить системный Python через pyenv

Системный Python управляется пакетным менеджером ОС (`apt`), а не pyenv. Команда `pyenv uninstall system` не сработает — pyenv управляет только теми версиями, которые сам установил.
