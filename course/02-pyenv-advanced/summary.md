# Конспект: Модуль 2 — pyenv: управление версиями

> Краткий справочник для повторения. Подходит для печати.

## Ключевые понятия

| Понятие | Суть (1 предложение) |
|---------|---------------------|
| Глобальная версия | Версия Python по умолчанию для всех терминалов, хранится в `~/.pyenv/version`. |
| Локальная версия | Версия Python для конкретной директории (и её поддиректорий), хранится в `.python-version`. |
| Сессионная версия | Версия Python для текущей сессии терминала, задаётся через переменную `PYENV_VERSION`. |
| `.python-version` | Текстовый файл в директории проекта, фиксирующий нужную версию Python. |
| `PYENV_VERSION` | Переменная окружения, задающая сессионную версию Python (наивысший приоритет). |
| Приоритет версий | Порядок разрешения: shell → local → global → system. |

## Важно запомнить

- pyenv проверяет источники в строгом порядке: `PYENV_VERSION` → `.python-version` → `~/.pyenv/version` → системный Python.
- Побеждает **первый найденный** источник — остальные игнорируются.
- `.python-version` действует на текущую директорию и все поддиректории (pyenv ищет файл вверх по дереву).
- Файл `.python-version` рекомендуется добавлять в git — он фиксирует версию Python для всей команды.
- `pyenv shell` — для временных экспериментов; не переживает закрытие терминала.
- `pyenv uninstall` удаляет версию Python, но не обновляет `.python-version` и `~/.pyenv/version`.
- При деинсталляции pyenv удаляются **все** установленные через него версии Python.

## Команды модуля

```bash
pyenv global 3.12.0           # установить глобальную версию
pyenv global                  # показать глобальную версию
pyenv global system           # вернуть системный Python как глобальный

pyenv local 3.11.7            # привязать версию к директории
pyenv local --unset           # удалить .python-version

pyenv shell 3.13.0            # установить версию для текущей сессии
pyenv shell --unset           # сбросить сессионную версию

pyenv version                 # показать текущую версию и её источник

pyenv uninstall 3.11.7        # удалить версию Python
pyenv uninstall -f 3.11.7     # удалить без подтверждения

cd ~/.pyenv && git pull        # обновить pyenv
pyenv update                  # обновить pyenv (если есть плагин pyenv-update)
rm -rf ~/.pyenv               # полное удаление pyenv
```

## Типичные ошибки (коротко)

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `python` показывает не ту версию | В директории есть `.python-version` или задана `PYENV_VERSION` | `pyenv version` покажет источник |
| `version 'X' is not installed` | Назначена версия, которой нет в pyenv | `pyenv install X` или изменить настройку |
| `python: command not found` после установки pyenv | Нет инициализации pyenv в `.bashrc` | Добавить строки `export PYENV_ROOT...` и `eval "$(pyenv init ...)"` |
| Удалили версию, но проекты сломались | `.python-version` ссылается на удалённую версию | Обновить `.python-version` или установить версию заново |
| После удаления pyenv ошибки при запуске терминала | Строки pyenv остались в `.bashrc` | Удалить строки из `.bashrc` |

## Схема приоритетов

```
         ┌─────────────────┐
         │  python вызван  │
         └────────┬────────┘
                  ▼
     ┌──── PYENV_VERSION? ────┐
     │ да                  нет│
     ▼                        ▼
  shell-версия    ┌── .python-version? ──┐
                  │ да                нет│
                  ▼                      ▼
            local-версия    ┌── ~/.pyenv/version? ──┐
                            │ да                 нет│
                            ▼                       ▼
                      global-версия          системный Python
```
