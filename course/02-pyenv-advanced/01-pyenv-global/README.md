# Переключение глобальной версии Python

> **Модуль 2 · Урок 1** | Время: ~20 мин

## Зачем нужна глобальная версия

В Модуле 1 вы установили одну или несколько версий Python через `pyenv install`. Однако после установки pyenv по умолчанию продолжает использовать системный Python — тот, что идёт с вашей ОС. Команда `pyenv global` позволяет выбрать, какая версия Python будет использоваться **по умолчанию во всех терминалах** и для всех проектов (если не задана более приоритетная настройка).

**Глобальная версия** — это версия Python, которую pyenv подставляет при вызове `python`, `python3` или `pip`, когда не задана ни локальная, ни сессионная версия.

## Как установить глобальную версию

Убедитесь, что нужная версия установлена:

```bash
pyenv versions
```

```
  system
  3.11.7
* 3.12.0 (set by /home/user/.pyenv/version)
```

Установите глобальную версию:

```bash
pyenv global 3.12.0
```

Проверьте результат:

```bash
python --version
```

```
Python 3.12.0
```

## Где хранится настройка

Команда `pyenv global` записывает выбранную версию в файл `~/.pyenv/version`:

```bash
cat ~/.pyenv/version
```

```
3.12.0
```

Это обычный текстовый файл с одной строкой — номером версии. Вы можете отредактировать его вручную, но лучше использовать команду `pyenv global`.

## Просмотр текущей глобальной версии

Чтобы узнать, какая версия установлена глобально, вызовите `pyenv global` без аргументов:

```bash
pyenv global
```

```
3.12.0
```

Команда `pyenv version` покажет текущую активную версию и её **источник**:

```bash
pyenv version
```

```
3.12.0 (set by /home/user/.pyenv/version)
```

Надпись `set by /home/user/.pyenv/version` подтверждает, что версия определена глобальной настройкой.

## Сброс на системный Python

Если вы хотите вернуть системный Python как глобальную версию:

```bash
pyenv global system
```

```bash
python3 --version
```

```
Python 3.12.3
```

Значение `system` — специальное: оно говорит pyenv «не вмешиваться» и пропустить вызов к системному Python, как если бы pyenv не был установлен.

## Несколько версий в глобальной настройке

`pyenv global` позволяет указать несколько версий:

```bash
pyenv global 3.12.0 3.11.7
```

В этом случае `python3.12` использует первую версию, `python3.11` — вторую. Команда `python` (без номера) вызовет первую версию из списка.

Это полезно, когда вы работаете с проектами, требующими разных минорных версий, и хотите, чтобы оба интерпретатора были доступны по имени.

## Сравнение с альтернативами

### pyenv vs conda

В conda аналогом глобальной версии служит **базовое окружение** (`base`). При установке Miniconda или Anaconda активируется `base`-окружение с определённой версией Python.

| Аспект | pyenv | conda |
|--------|-------|-------|
| Механизм | Файл `~/.pyenv/version` + shims | Активация окружения `base` |
| Область действия | Все терминалы, если нет local/shell | Текущий терминал (auto-activate) |
| Переключение | `pyenv global 3.12.0` | `conda activate base` / `conda install python=3.12` |
| Изоляция пакетов | Нет (только версия интерпретатора) | Да (окружение включает и пакеты) |

Главное отличие: pyenv управляет **только версиями интерпретатора**, а conda — **целыми окружениями** (интерпретатор + пакеты). Для изоляции пакетов в связке с pyenv используется `venv` (Модули 4–5).

## Частые ошибки

### Ошибка 1 — Забыть, что global влияет на все терминалы

Команда `pyenv global` меняет версию Python **для всего пользователя**. Если вы установили `pyenv global 3.13.0` для экспериментов, это затронет все открытые и новые терминалы. Прежде чем менять глобальную версию, подумайте, не лучше ли использовать `pyenv shell` (Урок 3) для временных экспериментов.

### Ошибка 2 — Путать global и system

- `pyenv global 3.12.0` — устанавливает версию 3.12.0, установленную через pyenv, как глобальную.
- `pyenv global system` — говорит pyenv использовать системный Python (тот, что установлен через `apt`).

Это разные вещи. `system` — не версия, а указание «использовать Python из `/usr/bin/`».

### Ошибка 3 — Установить global для несуществующей версии

Если указать версию, которая не установлена через pyenv:

```bash
pyenv global 3.10.0
```

pyenv запишет её в файл `~/.pyenv/version`, но при попытке вызвать `python` вы получите:

```
pyenv: version '3.10.0' is not installed (set by /home/user/.pyenv/version)
```

Всегда проверяйте, что версия установлена (`pyenv versions`), прежде чем назначать её глобальной.
