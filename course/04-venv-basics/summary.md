# Конспект: Модуль 4 — venv: создание и работа

> Краткий справочник для повторения. Подходит для печати.

## Ключевые понятия

| Понятие | Суть (1 предложение) |
|---------|---------------------|
| venv | Модуль стандартной библиотеки Python для создания изолированных виртуальных окружений. |
| виртуальное окружение | Изолированная директория с собственным Python, pip и site-packages, не затрагивающая системный Python. |
| изоляция зависимостей | Разделение пакетов проекта от глобальных и других проектов — каждый проект со своими зависимостями. |
| VIRTUAL_ENV | Переменная окружения, устанавливаемая при активации venv; содержит путь к директории окружения. |

## Важно запомнить

- venv изолирует пакеты проекта от глобального Python и других проектов.
- Окружение создаётся командой `python -m venv <путь>`; часто используется имя `venv` или `.venv`.
- Активация: `source venv/bin/activate`; деактивация: `deactivate`.
- При активации PATH меняется — `python` и `pip` указывают внутрь окружения.
- pip в активированном venv устанавливает пакеты только в это окружение.
- Директорию venv не коммитят в git; в `.gitignore` добавляют `venv/` или `.venv/`.

## Команды модуля

```bash
python -m venv venv          # создать окружение в каталоге venv
source venv/bin/activate      # активировать (bash/zsh)
deactivate                    # деактивировать
echo $VIRTUAL_ENV             # проверить активное окружение
which python                  # путь к python после активации
pip list                      # пакеты в текущем окружении
```

## Типичные ошибки (коротко)

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Путать venv и pyenv | Разные инструменты: pyenv — версии Python, venv — изоляция пакетов | pyenv — интерпретатор; venv — окружение для пакетов |
| `venv myenv` как команду | venv — модуль, не отдельная программа | `python -m venv myenv` |
| `activate` без `source` | Не выполнится в дочернем процессе | `source venv/bin/activate` |
| pip до активации | Пакеты установятся глобально | Сначала активировать venv, потом `pip install` |
| Коммитить venv в git | Окружение большое и воспроизводимо | Добавить `venv/` в `.gitignore` |

## Схема

```
Системный Python (или pyenv)
        │
        ▼
python -m venv venv
        │
        ├── venv/bin/python    ← симлинк/копия
        ├── venv/bin/pip
        ├── venv/bin/activate
        ├── venv/lib/python3.x/site-packages/   ← пакеты проекта
        └── venv/pyvenv.cfg    ← ссылка на базовый Python

source venv/bin/activate
        │
        ▼
PATH = venv/bin:$PATH  →  python, pip указывают внутрь venv
VIRTUAL_ENV = /path/to/venv
```
