# Модуль 4. venv: создание и работа

> **Время:** ~2–3 дня (при темпе 1–2 часа в день)

## Чему вы научитесь

- Объяснять, зачем нужны виртуальные окружения и что даёт изоляция зависимостей.
- Создавать виртуальное окружение командой `python -m venv`.
- Активировать и деактивировать окружение в bash/zsh.
- Понимать механизм активации: PATH, переменные окружения, prompt.
- Устанавливать пакеты внутри активированного окружения.
- Различать структуру директории venv и её назначение.

## Что будет рассмотрено

| Тема | Описание |
|------|----------|
| venv и изоляция | Зачем нужны виртуальные окружения, связь с site-packages. |
| Создание venv | `python -m venv`, выбор пути и имени каталога. |
| Активация и деактивация | `source venv/bin/activate`, `deactivate`. |
| Механизм активации | Изменение PATH, переменная VIRTUAL_ENV, prompt. |
| pip внутри venv | Установка пакетов изолированно от системного Python. |
| Структура venv | bin/, lib/, pyvenv.cfg, связь с базовым Python. |

## Инструменты и команды

| Команда / инструмент | Назначение |
|---------------------|-----------|
| `python -m venv <dir>` | Создать виртуальное окружение. |
| `source venv/bin/activate` | Активировать окружение (bash/zsh). |
| `deactivate` | Деактивировать окружение. |
| `pip install` (в активированном venv) | Установить пакет в окружение. |

## Итоги модуля

### Что вы изучили

- Виртуальное окружение (venv) — изолированная среда для пакетов проекта.
- Создание через `python -m venv`; активация через `source venv/bin/activate`.
- Механизм активации: PATH, VIRTUAL_ENV, изменение prompt.
- pip в активированном venv устанавливает пакеты только в это окружение.
- Структура venv: bin/, lib/, pyvenv.cfg — не коммитить в git.

### Чеклист навыков

Отметьте то, что вы уверенно можете сделать:

- [ ] Объяснить, зачем нужна изоляция зависимостей и чем venv отличается от pyenv.
- [ ] Создать виртуальное окружение командой `python -m venv`.
- [ ] Активировать и деактивировать окружение в Linux.
- [ ] Определить, активно ли окружение (по prompt, which python, VIRTUAL_ENV).
- [ ] Установить пакет через pip в активированном venv.
- [ ] Объяснить, что внутри директории venv и почему её не коммитить в git.

### Ключевые команды

```bash
python -m venv venv              # создать окружение в каталоге venv
source venv/bin/activate         # активировать (bash/zsh)
deactivate                       # деактивировать
pip install <package>            # в активированном venv — установить пакет
```
