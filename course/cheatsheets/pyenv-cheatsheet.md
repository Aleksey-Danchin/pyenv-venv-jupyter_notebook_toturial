# Справочник: pyenv

> Краткий справочник команд pyenv. Подробности — в соответствующих уроках.

## Установка и настройка

| Команда | Описание | Пример |
|---------|----------|--------|
| `curl https://pyenv.run \| bash` | Установить pyenv через официальный установщик | — |
| `pyenv --version` | Показать версию pyenv | `pyenv --version` |
| `cd ~/.pyenv && git pull` | Обновить pyenv до последней версии | — |

## Установка версий Python

| Команда | Описание | Пример |
|---------|----------|--------|
| `pyenv install --list` | Показать все доступные для установки версии | `pyenv install --list` |
| `pyenv install <version>` | Установить (скомпилировать) указанную версию Python | `pyenv install 3.12.0` |
| `pyenv uninstall <version>` | Удалить установленную версию Python | `pyenv uninstall 3.11.7` |

## Просмотр версий

| Команда | Описание | Пример |
|---------|----------|--------|
| `pyenv versions` | Показать все установленные версии (активная отмечена `*`) | `pyenv versions` |
| `pyenv version` | Показать текущую активную версию и её источник | `pyenv version` |

## Переключение версий

| Команда | Описание | Пример |
|---------|----------|--------|
| `pyenv global <version>` | Установить глобальную версию Python | `pyenv global 3.12.0` |
| `pyenv local <version>` | Установить версию для текущей директории (создаёт `.python-version`) | `pyenv local 3.11.7` |
| `pyenv shell <version>` | Установить версию для текущей сессии shell | `pyenv shell 3.13.0` |
| `pyenv shell --unset` | Сбросить версию сессии | `pyenv shell --unset` |

## Служебные

| Команда | Описание | Пример |
|---------|----------|--------|
| `pyenv rehash` | Пересоздать shims (обычно выполняется автоматически) | `pyenv rehash` |
| `pyenv which <command>` | Показать полный путь к исполняемому файлу через pyenv | `pyenv which python` |
