> **Время:** ~2 дня (при темпе 1–2 часа в день)

## Чему вы научитесь

| Команда / инструмент | Назначение |
|---------------------|-----------|
| `pip install ipykernel` | Установить ipykernel в окружение |
| `python -m ipykernel install --user --name=... --display-name=...` | Зарегистрировать окружение как ядро Jupyter |
| `jupyter kernelspec list` | Показать зарегистрированные ядра |
| `jupyter kernelspec remove <имя>` | Удалить ядро |

## Итоги модуля

### Что вы изучили

- **Ядро Jupyter** — интерпретатор, который выполняет код в ячейках; код идёт в окружении ядра, а не в активированном venv терминала.
- **ipykernel** — пакет для регистрации Python-окружения как ядра; устанавливается в venv, после чего окружение появляется в Kernel → Change kernel.
- **kernelspec** — описание ядра (путь к интерпретатору, метаданные); хранится в `~/.local/share/jupyter/kernels/`.
- Краевые случаи: системное ядро вместо venv; несколько Jupyter-серверов — как диагностировать и исправлять.

### Чеклист навыков

Отметьте то, что вы уверенно можете сделать:

- [ ] Объяснить, что такое ядро Jupyter и чем оно отличается от «Python в терминале»
- [ ] Установить ipykernel в venv и зарегистрировать окружение как ядро
- [ ] Переключить ядро в открытом ноутбуке
- [ ] Просмотреть список ядер и удалить ненужное
- [ ] Найти причину, если Jupyter использует системный Python вместо venv
- [ ] Разобраться с несколькими Jupyter-серверами на разных портах

### Ключевые команды

```bash
pip install ipykernel
python -m ipykernel install --user --name myenv --display-name "Python (myenv)"
jupyter kernelspec list
jupyter kernelspec remove myenv
```
