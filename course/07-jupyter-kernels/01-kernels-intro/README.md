# Ядра (kernels): что это, какие бывают, как переключить

> **Модуль 7 · Урок 1** | Время: ~15 мин

## Основной контент

Когда вы выполняете код в ячейке Jupyter, этот код запускается не в вашем терминале — он выполняется **ядром** (kernel). Ядро — это отдельный процесс Python (или другого интерпретатора), который Jupyter запускает и с которым общается через протокол.

**Ядро** (kernel) — это среда выполнения кода в ноутбуке: интерпретатор Python и все пакеты, установленные в его окружении.

### Важно понять различие

- **Терминал, в котором вы запустили `jupyter notebook`** — это одно окружение (например, активированный venv).
- **Ядро, с которым работает ноутбук** — это другое окружение. Оно может совпадать с тем, откуда запущен Jupyter, а может и нет.

Если вы установили Jupyter в venv `project-env`, но ядро по умолчанию указывает на системный Python — код в ячейках будет выполняться в системном окружении, без пакетов из `project-env`. Поэтому важно уметь регистрировать venv как ядро и переключать ядро в ноутбуке.

### Какие ядра бывают

- **Python** — стандартное ядро для Python. Может указывать на системный Python или на конкретный venv.
- **ipykernel** — пакет, который позволяет зарегистрировать любое Python-окружение (в том числе venv) как ядро Jupyter.
- Ядра других языков (R, Julia и т.д.) — для них используются свои пакеты, аналогичные ipykernel.

### Как переключить ядро

В интерфейсе Jupyter Notebook: **Kernel → Change kernel →** выбрать нужное ядро из списка. После смены все последующие ячейки выполняются в окружении выбранного ядра.

Проверить, какой Python использует ядро, можно прямо в ноутбуке:

```python
import sys
sys.executable
```

Эта команда покажет путь к интерпретатору, в окружении которого выполняется код.

## Частые ошибки

### Ошибка 1 — Думать, что код выполняется в том же Python, что и терминал

Ячейки выполняются в окружении **выбранного ядра**, а не в окружении активированного venv в терминале. Если ядро указывает на системный Python, а пакеты вы ставили в venv — `import` провалится. Решение: зарегистрировать venv как ядро и переключить ядро в ноутбуке.

### Ошибка 2 — Путать «активированный venv» и «ядро Jupyter»

Активация venv в терминале влияет на команды `python`, `pip`, `jupyter` в этом терминале. Ядро — это отдельный процесс, который Jupyter запускает по своему списку зарегистрированных ядер. Чтобы ноутбук использовал ваш venv, нужно зарегистрировать этот venv как ядро и выбрать его в Kernel → Change kernel.

### Ошибка 3 — Не проверять `sys.executable` при неожиданных `ImportError`

Если `pip list` в терминале показывает пакет, а в ячейке `import` падает — скорее всего, ядро указывает на другое окружение. Проверьте `sys.executable` в ноутбуке и убедитесь, что путь совпадает с `which python` в активированном venv.
