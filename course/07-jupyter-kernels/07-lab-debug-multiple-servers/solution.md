# Эталонное решение: несколько Jupyter-серверов на разных портах

## Диагностика

1. `jupyter notebook list` — показывает запущенные серверы и их URL (порты, токены).
2. `ps aux | grep jupyter` — показывает процессы Jupyter с PID.
3. `lsof -i :8888` или `lsof -i :8889` — показывает, какой процесс слушает порт.

## Шаги решения

1. Определить серверы: `jupyter notebook list`
2. Выбрать один для работы (например, порт 8888).
3. Остановить лишний: `kill <PID>` или в терминале, где запущен сервер, нажать Ctrl+C.
4. Убедиться, что остался один сервер: снова `jupyter notebook list`.

## Ожидаемый результат

- Один работающий Jupyter-сервер (или ни одного после завершения работы).
- Понимание, как проверять и останавливать серверы.

## Команды для справки

```bash
jupyter notebook list    # список запущенных серверов
jupyter notebook --port 9999   # запуск на конкретном порту
ps aux | grep jupyter    # процессы Jupyter
kill <PID>               # остановить процесс
```
