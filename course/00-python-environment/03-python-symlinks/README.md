# Симлинки: `python` -> `python3` -> `python3.x`

> **Модуль 0 · Урок 03** | Время: ~5 мин

## Содержание

**Симлинк (symbolic link)** — это специальный файловый объект-ссылка на другой файл или директорию.  
В Python-среде Ubuntu часто встречается цепочка:

```bash
python -> python3 -> python3.x
```

Проверка:

```bash
ls -l /usr/bin/python3
readlink -f /usr/bin/python3
```

- `ls -l` показывает, является ли файл ссылкой и куда она указывает.
- `readlink -f` разворачивает всю цепочку до конечного файла.

Иногда полезно посмотреть и `python`:

```bash
ls -l /usr/bin/python
```

Если файла нет, это нормально: на некоторых системах доступен только `python3`.

## Зачем это знать

Когда «вдруг поменялся Python», это часто результат изменения симлинка или порядка `PATH`, а не «поломка Python».

## Частые ошибки

### Ошибка 1 — путать симлинк и копию файла

Симлинк не содержит отдельную копию бинаря; он только указывает на цель.

### Ошибка 2 — смотреть только первый уровень ссылки

Промежуточный симлинк может указывать на другой симлинк. Нужна полная цепочка (`readlink -f`).

### Ошибка 3 — редактировать `/usr/bin` вручную

Ручная подмена ссылок в системных каталогах приводит к трудноотлавливаемым сбоям.
