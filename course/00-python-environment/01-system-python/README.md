# Где лежит системный Python (`which`, `whereis`, `/usr/bin/python3`)

> **Модуль 0 · Урок 01** | Время: ~5 мин

## Содержание

**Системный Python** — это Python, установленный пакетным менеджером ОС и используемый системными инструментами.  
В Ubuntu чаще всего основная точка входа — `/usr/bin/python3`.

Начнём с двух базовых команд:

- `which` показывает, какой исполняемый файл shell запустит по имени команды.
- `whereis` показывает известные системе расположения бинарей, исходников и документации.

Пример:

```bash
which python3
whereis python3
```

Возможный результат:

```bash
/usr/bin/python3
python3: /usr/bin/python3 /usr/lib/python3 /usr/share/man/man1/python3.1.gz
```

Дополнительно полезно проверить, не является ли путь симлинком:

```bash
ls -l /usr/bin/python3
```

Команда `ls -l` показывает тип файла и цель ссылки. В следующих уроках мы разберём это подробнее.

## Практика в 3 шага

1. Выполните `which python3`.
2. Выполните `whereis python3`.
3. Сравните вывод и зафиксируйте: один путь запуска и несколько системных расположений.

## Частые ошибки

### Ошибка 1 — считать `which` и `whereis` взаимозаменяемыми

`which` отвечает на вопрос «что запустится сейчас», а `whereis` — «где в системе встречается этот инструмент».

### Ошибка 2 — делать вывод по `python`, а не по `python3`

В Ubuntu команда `python` может отсутствовать или быть симлинком. Для предсказуемости проверяйте `python3`.

### Ошибка 3 — игнорировать путь `/usr/bin/python3`

Этот путь обычно критичен для системных сценариев. Его нельзя произвольно подменять.
