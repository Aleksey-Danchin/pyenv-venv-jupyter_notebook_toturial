# Что такое shims — предвосхищение pyenv

> **Модуль 0 · Урок 06** | Время: ~5 мин

## Содержание

**Shim** — это прокси-исполняемый файл, который принимает вызов команды (`python`, `pip`)  
и перенаправляет его на нужный реальный бинарник по заданным правилам.

Идея важна для pyenv:

1. Вы набираете `python`.
2. Запускается shim.
3. Shim определяет, какую версию Python выбрать (глобальную, локальную, для сессии).
4. Выполняется соответствующий интерпретатор.

На этом этапе вам не нужно настраивать pyenv — достаточно понять сам механизм проксирования команд.

## Ментальная модель

- без shims: shell напрямую ищет `python` по `PATH`;
- с shims: первым находится прокси-файл, а дальше выбор делает уже инструмент управления версиями.

Эта модель объясняет, почему после установки pyenv `which python` начинает показывать путь в директории shims.

## Что запомнить перед модулем 1

- shims не заменяют системный Python;
- shims добавляют управляемый слой выбора версии;
- корректный `PATH` критичен для работы этой схемы.

## Частые ошибки

### Ошибка 1 — думать, что shim это отдельная версия Python

Shim не интерпретатор. Это только маршрутизатор вызова.

### Ошибка 2 — ожидать работу pyenv без корректного PATH

Если shims не попали в начало `PATH`, команда будет обходить pyenv.

### Ошибка 3 — пытаться «чинить» shims ручным редактированием системных ссылок

Shim-механизм должен настраиваться инструментом (pyenv), а не ручной правкой `/usr/bin`.
