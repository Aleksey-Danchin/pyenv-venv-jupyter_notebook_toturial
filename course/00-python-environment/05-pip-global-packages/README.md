# Что такое pip и куда он устанавливает пакеты глобально

> **Модуль 0 · Урок 05** | Время: ~25 мин

## Содержание

`pip` — менеджер пакетов Python. Он устанавливает библиотеки в `site-packages`.  
Без виртуального окружения установка обычно идёт в системные или пользовательские пути.

Проверьте, к какому Python привязан текущий pip:

```bash
pip3 --version
python3 -m pip --version
```

Рекомендуемый подход — запускать pip как модуль Python:

```bash
python3 -m pip install <package>
```

Так вы явно управляете интерпретатором, который выполняет установку.

Посмотреть, где находятся директории Python:

```bash
python3 -m site
```

В выводе будут пути для `site-packages` и пользовательских установок.

## Почему глобальная установка рискованна

- разные проекты могут требовать разные версии одной библиотеки;
- глобальные обновления ломают старые проекты;
- сложно воспроизвести окружение на другой машине.

Именно поэтому далее в курсе используется `venv`.

## Частые ошибки

### Ошибка 1 — использовать `pip` без проверки, к какому Python он относится

Команда может указывать не на тот интерпретатор, который вы ожидаете.

### Ошибка 2 — смешивать системные и пользовательские установки

Это затрудняет диагностику: пакет «как будто установлен», но не импортируется в нужном окружении.

### Ошибка 3 — полагаться на глобальные пакеты для всех проектов

В итоге версии библиотек начинают конфликтовать между проектами.
