# Что такое PATH и как система находит исполняемые файлы

> **Модуль 0 · Урок 02** | Время: ~5 мин

## Содержание

`PATH` — это переменная окружения со списком директорий, где shell ищет команды.  
Поиск идёт слева направо: первый найденный исполняемый файл и будет запущен.

Посмотреть `PATH`:

```bash
echo $PATH
```

Типичный вывод:

```bash
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

Чтобы понять, какой именно Python выберет shell:

```bash
which python3
type -a python3
```

- `type -a` показывает все найденные варианты команды в порядке приоритета.
- `which` показывает первый, то есть реально запускаемый сейчас.

## Мини-эксперимент

1. Выполните `type -a python3`.
2. Найдите в выводе самый верхний путь.
3. Сравните с `which python3` — значения должны совпасть.

## Почему это важно

Когда вы позже установите pyenv, в начале `PATH` появится директория с `shims`.  
Именно поэтому команда `python` начнёт вести себя по-другому без удаления системного Python.

## Частые ошибки

### Ошибка 1 — не учитывать порядок директорий в PATH

Наличие бинаря в системе не гарантирует его запуск. Решает позиция директории в `PATH`.

### Ошибка 2 — вручную «чинить» системные файлы вместо проверки PATH

Часто проблема не в бинаре, а в порядке поиска команд.

### Ошибка 3 — изменять PATH без понимания последствий

Даже одна лишняя директория в начале `PATH` может перенаправить запуск на другой Python.
