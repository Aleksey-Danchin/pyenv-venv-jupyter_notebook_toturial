## Вопрос 1

Чем Jupyter Notebook отличается от обычного Python-скрипта (.py)?

- A) Ничем — это тот же код, только открывается в Jupyter
- B) Ноутбук хранит ячейки с кодом и текст; выполняется по одной ячейке; смешивает код и документацию
- C) Jupyter работает быстрее, чем интерпретатор Python
- D) .py-файлы нельзя открыть в Jupyter

<details><summary>Ответ</summary>

**B)** — Ноутбук (notebook) — это документ из ячеек: Code (исполняемый Python), Markdown (документация), Raw. Код выполняется по ячейкам, результат отображается inline. Обычный .py — линейный скрипт, выполняемый целиком.

</details>

## Вопрос 2

Куда рекомендуется устанавливать Jupyter?

- A) Глобально через `sudo pip install jupyter`
- B) В виртуальное окружение (venv) каждого проекта
- C) Только через системный пакетный менеджер (`apt install jupyter`)
- D) В домашнюю директорию без venv

<details><summary>Ответ</summary>

**B)** — Jupyter устанавливают в venv, как и другие зависимости проекта. Это изолирует версии Jupyter и пакетов между проектами. Глобальная установка приводит к конфликтам и «зоопарку» зависимостей.

</details>

## Вопрос 3

Что происходит при выполнении `jupyter notebook` в терминале?

- A) Открывается текстовый редактор с ноутбуком
- B) Запускается локальный веб-сервер; браузер открывает интерфейс
- C) Jupyter компилирует все .ipynb в исполняемые файлы
- D) Устанавливается Jupyter, если он ещё не установлен

<details><summary>Ответ</summary>

**B)** — `jupyter notebook` запускает **notebook-сервер** — локальный веб-сервер. По умолчанию он открывает браузер с файловым интерфейсом. Работа с ноутбуками идёт через браузер.

</details>

---

## Вопрос 4

Как остановить Jupyter Notebook-сервер?

- A) Закрыть вкладку браузера
- B) Нажать Ctrl+C в терминале, где запущен `jupyter notebook`
- C) Выполнить `jupyter stop`
- D) Закрыть все ноутбуки в интерфейсе

<details><summary>Ответ</summary>

**B)** — Сервер работает в том терминале, где вы вызвали `jupyter notebook`. Ctrl+C отправляет сигнал прерывания и останавливает сервер. Закрытие браузера сервер не останавливает.

</details>

## Вопрос 5

Какой тип ячейки используется для исполняемого Python-кода?

- A) Markdown
- B) Raw
- C) Code
- D) Script

<details><summary>Ответ</summary>

**C)** — **Code** — ячейка с исполняемым кодом. Markdown — для документации и разметки. Raw — для текста без обработки (редко используется).

</details>

## Вопрос 6

В чём разница между Shift+Enter и Ctrl+Enter при выполнении ячейки?

- A) Нет разницы — обе комбинации делают одно и то же
- B) Shift+Enter выполняет ячейку и переходит к следующей; Ctrl+Enter выполняет и остаётся на текущей
- C) Ctrl+Enter переключает режим команд; Shift+Enter — режим редактирования
- D) Shift+Enter сохраняет ноутбук; Ctrl+Enter выполняет ячейку

<details><summary>Ответ</summary>

**B)** — Shift+Enter выполняет ячейку и переводит фокус на следующую (удобно для последовательного выполнения). Ctrl+Enter выполняет ячейку, но курсор остаётся на текущей.

</details>

## Вопрос 7

Чтобы вставить новую ячейку *ниже* текущей, в режиме команд нужно нажать:

- A) A (above)
- B) B (below)
- C) I (insert)
- D) O (об этом нет в уроках — используется B)

<details><summary>Ответ</summary>

**D)** — В режиме команд (синяя полоска слева) **B** вставляет ячейку ниже (below), **A** — выше (above). Буквы происходят от «above» и «below».

</details>

## Вопрос 8

Вы создали venv и установили в него `jupyter notebook`. Команда `which jupyter` показывает путь внутри venv. Это значит:

- A) Jupyter установлен глобально
- B) Jupyter установлен в активированном venv; путь в venv/bin
- C) Jupyter — это скрипт pyenv
- D) which не работает с venv

<details><summary>Ответ</summary>

**B)** — При активации venv (`source venv/bin/activate`) в начало PATH добавляется `venv/bin`. Команда `which jupyter` покажет `.../venv/bin/jupyter`, если пакет установлен в этом окружении.

</details>

## Вопрос 9

Файл ноутбука имеет расширение:

- A) .jnb
- B) .ipynb
- C) .notebook
- D) .py

<details><summary>Ответ</summary>

**B)** — **.ipynb** (IPython Notebook). Формат — JSON: метаданные, ячейки, вывод — всё в одном файле. Расширение унаследовано от проекта IPython Notebook, предшественника Jupyter.

</details>

## Вопрос 10

Режим команд (синяя полоска слева у ячейки) и режим редактирования (зелёная полоска) переключаются клавишами:

- A) Ctrl+Shift
- B) Esc и Enter
- C) Tab и Shift+Tab
- D) F2 и F3

<details><summary>Ответ</summary>

**B)** — **Esc** переключает в режим команд (навигация по ячейкам, горячие клавиши A, B, D, Y, M). **Enter** переключает в режим редактирования (ввод текста и кода в ячейку).

</details>
