# Экспорт ноутбука

> **Модуль 6 · Урок 10** | Время: ~15 мин

## Зачем экспортировать ноутбук

Ноутбук (.ipynb) — формат Jupyter: JSON с ячейками, выводом, метаданными. Для презентаций, отчётов или обмена кодом часто нужны другие форматы:

- **HTML** — просмотр в браузере, удобно для отчётов.
- **PDF** — печать и рассылка.
- **Script (.py)** — чистый Python-код без ячеек, для версионного контроля или запуска в терминале.

Для конвертации используется **nbconvert**[^глоссарий]([Глоссарий](../../references/glossary.md)) — утилита из пакета Jupyter.

## nbconvert: командная строка

`nbconvert` входит в пакет `nbconvert`, который обычно уже установлен вместе с `jupyter notebook`. Проверка:

```bash
jupyter nbconvert --version
```

Экспорт в HTML (по умолчанию):

```bash
jupyter nbconvert --to html notebook.ipynb
```

Создаётся `notebook.html` в той же директории.

Экспорт в Python-скрипт:

```bash
jupyter nbconvert --to script notebook.ipynb
```

Создаётся `notebook.py` — код из ячеек Code, разделённый комментариями с именами ячеек.

Экспорт в PDF:

```bash
jupyter nbconvert --to pdf notebook.ipynb
```

> **Зависимость:** для PDF нужен LaTeX (например, `texlive-xetex`). Без него команда выдаст ошибку.

```bash
sudo apt install texlive-xetex
```

## Экспорт через интерфейс

В Jupyter Notebook: **File** → **Download as** → выбрать формат.

- **HTML (.html)** — сохраняет в папку загрузок браузера.
- **PDF via LaTeX (.pdf)** — требует LaTeX.
- **Python (.py)** — скрипт с кодом ячеек.

Интерфейс вызывает тот же `nbconvert` под капотом.

## Различия форматов

| Формат | Содержимое | Когда использовать |
|--------|------------|---------------------|
| HTML | Код, вывод, Markdown (отрендеренный) | Отчёты, демонстрация |
| PDF | То же, для печати | Документы, отчёты для печати |
| .py | Только код из ячеек Code | Версионный контроль, запуск как скрипт |

Экспорт в .py **не воспроизводит** ноутбук полностью: Markdown и вывод теряются. Для полного воспроизведения нужен исходный .ipynb.

## Частые ошибки

### Ошибка 1 — PDF не создаётся: «LaTeX not found»

Установите LaTeX, например: `sudo apt install texlive-xetex texlive-fonts-recommended`. Альтернатива — экспортировать в HTML и печатать из браузера (Ctrl+P → Save as PDF).

### Ошибка 2 — Путать .py экспорт с полным воспроизведением

`.py` — это только код. Запуск `python notebook.py` выполнит код, но не восстановит ячейки, Markdown и сохранённый вывод. Для совместной работы и воспроизводимости передавайте .ipynb.

### Ошибка 3 — nbconvert не найден

Если `jupyter nbconvert` не работает, установите явно: `pip install nbconvert`. Пакет `jupyter` может подтянуть его как зависимость, но не всегда.

### Ошибка 4 — Экспорт «пустого» HTML

Если в ячейках не был выполнен код (нет вывода), HTML может выглядеть пустым. Выполните все ячейки (Cell → Run All) перед экспортом, чтобы вывод попал в файл.
