# Базовые горячие клавиши

> **Модуль 6 · Урок 6** | Время: ~10 мин

## Два режима ячейки

В Jupyter ячейка может находиться в одном из двух режимов:

| Режим | Признак | Действия |
|-------|---------|----------|
| **Режим команд (Command mode)** | Толстая синяя рамка слева, без курсора ввода | Навигация, вставка, удаление, смена типа ячейки |
| **Режим редактирования (Edit mode)** | Тонкая зелёная рамка, курсор в ячейке | Ввод и правка текста/кода |

**Esc** — перейти в режим команд.  
**Enter** — перейти в режим редактирования (в выбранной ячейке).

## Выполнение ячеек

| Клавиша | Действие |
|---------|----------|
| **Shift+Enter** | Выполнить ячейку и перейти к следующей (создаёт новую, если это последняя). |
| **Ctrl+Enter** | Выполнить ячейку и остаться в ней. |
| **Alt+Enter** | Выполнить ячейку и вставить новую снизу. |

## Навигация и выбор

| Клавиша | Действие |
|---------|----------|
| **↑ / ↓** или **j / k** | Перейти к предыдущей/следующей ячейке (в режиме команд). |
| **Enter** | Войти в режим редактирования выбранной ячейки. |

## Вставка и удаление ячеек

| Клавиша | Действие |
|---------|----------|
| **A** (above) | Вставить ячейку **выше** текущей. |
| **B** (below) | Вставить ячейку **ниже** текущей. |
| **D, D** (два раза D) | Удалить текущую ячейку. |
| **Z** | Отменить последнее удаление ячейки. |

## Смена типа ячейки

В режиме команд:

| Клавиша | Тип |
|---------|-----|
| **Y** | Code |
| **M** | Markdown |
| **R** | Raw |

## Сохранение и прочее

| Клавиша | Действие |
|---------|----------|
| **Ctrl+S** | Сохранить ноутбук. |
| **Ctrl+Shift+-** | Разделить ячейку в месте курсора. |
| **Shift+M** | Объединить выбранные ячейки. |

## Как запомнить

Сначала освойте минимум: **Esc** (режим команд) → **Enter** (режим редактирования), **Shift+Enter** (выполнить и дальше), **A/B** (вставить ячейку), **D,D** (удалить). Остальное подтянется по мере работы.

Полный список: **Help → Keyboard Shortcuts** в меню Jupyter.

## Частые ошибки

### Ошибка 1 — Не различать режимы

В режиме команд клавиши A, B, Y, M меняют структуру. В режиме редактирования те же буквы вводятся как текст. Следите за рамкой: синяя — команды, зелёная — редактирование.

### Ошибка 2 — Привыкать только к мыши

Горячие клавиши ускоряют работу в разы. Выполнение, вставка и удаление ячеек без мыши — базовый навык для продуктивной работы.

### Ошибка 3 — Забывать сохранять

Jupyter сохраняет при выполнении ячеек, но не при любом изменении Markdown без Run. Периодически нажимайте **Ctrl+S**, особенно перед закрытием вкладки.
