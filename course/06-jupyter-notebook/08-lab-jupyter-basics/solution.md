# Эталонное решение: Jupyter Notebook — установка, запуск и ячейки

## Шаги решения

1. Создать директорию и перейти в неё.
2. Опционально: задать версию Python через `pyenv local` (если используется pyenv).
3. Создать виртуальное окружение и активировать его.
4. Установить Jupyter Notebook.
5. Запустить notebook-сервер.
6. В браузере: создать новый ноутбук, добавить и выполнить ячейки.
7. Сохранить и переименовать ноутбук в `intro.ipynb`.
8. Остановить сервер (Ctrl+C).

## Команды (терминал)

```bash
mkdir -p ~/lab-jupyter-basics
cd ~/lab-jupyter-basics

# Если используется pyenv:
pyenv local 3.11.7   # или другая установленная версия

# Создание и активация venv
python -m venv venv
source venv/bin/activate

# Установка Jupyter
pip install jupyter notebook

# Проверка
jupyter --version

# Запуск сервера (в этой же сессии терминала)
jupyter notebook
```

## Действия в браузере

1. В открывшемся интерфейсе Jupyter: **New** → **Python 3** (или **Python (venv)**).
2. В первой ячейке (Code) ввести: `print("Hello, Jupyter!")`, нажать **Shift+Enter**.
3. Нажать **B** (в режиме команд) — вставить ячейку ниже.
4. Нажать **M** — переключить новую ячейку на Markdown.
5. Ввести: `## Введение` и краткий текст, например: `Это мой первый ноутбук в Jupyter.`
6. **File** → **Rename Notebook** → ввести `intro.ipynb`, сохранить.
7. **Ctrl+S** — сохранить.
8. В терминале: **Ctrl+C** дважды — остановить сервер.

## Ожидаемый результат

- Файл `~/lab-jupyter-basics/intro.ipynb` существует.
- В ноутбуке есть ячейка Code с `print("Hello, Jupyter!")`.
- В ноутбуке есть ячейка Markdown с `## Введение`.
- Директория `~/lab-jupyter-basics/venv/` существует.
