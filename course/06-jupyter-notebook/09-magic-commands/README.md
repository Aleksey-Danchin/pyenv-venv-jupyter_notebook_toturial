# Магические команды

> **Модуль 6 · Урок 9** | Время: ~15 мин

## Что такое магические команды

**Магические команды** (magics)[^глоссарий]([Глоссарий](../../references/glossary.md)) — это расширения IPython (и Jupyter), которые начинаются с `%` или `%%`. Они позволяют вызывать shell, измерять время, загружать скрипты и выполнять другие действия, недоступные в обычном Python.

Jupyter использует IPython как ядро по умолчанию, поэтому все магические команды IPython доступны в ноутбуке.

## Line magics и cell magics

- **Line magic** (`%команда`) — действует на одну строку. Пишется в начале ячейки или после кода.
- **Cell magic** (`%%команда`) — действует на всю ячейку. Записывается в первой строке ячейки.

```python
%timeit sum(range(1000))    # line magic — одна строка
```

```python
%%time
x = [i**2 for i in range(100000)]
y = sum(x)
```
`%%time` измеряет время выполнения всей ячейки.

## Полезные магические команды

### Выполнение shell-команд: `!`

Префикс `!` выполняет команду в системном shell. Это не magic в строгом смысле, но используется так же часто.

```python
!ls -la
!pwd
!which python
```

```python
!pip list
```

> **Важно:** `!pip install` устанавливает в тот Python, который видит shell по умолчанию. Если Jupyter запущен из активированного venv, `!pip` будет использовать pip из venv. Для надёжности используйте `%pip install` (см. ниже).

### Время: `%timeit`, `%%time`

`%timeit` — многократный запуск выражения и вывод среднего времени:

```python
%timeit sum(range(1000))
```

```
2.1 µs ± 45.2 ns per loop (mean ± std. dev. of 7 runs, 100000 loops each)
```

`%%time` — время выполнения всей ячейки (один прогон):

```python
%%time
result = [x**2 for x in range(1000000)]
```

### Запуск скрипта: `%run`

Выполняет Python-файл в текущем ядре (переменные остаются доступны):

```python
%run script.py
```

```python
%run -i script.py   # -i: скрипт видит переменные ноутбука
```

### Переменные окружения: `%env`

Просмотр и установка переменных окружения:

```python
%env
%env MY_VAR=value
%env PATH
```

### Рабочая директория и файлы: `%pwd`, `%cd`, `%ls`

```python
%pwd
%cd /path/to/dir
%ls
```

### pip: `%pip`

Установка пакетов в окружение текущего ядра (рекомендуемый способ):

```python
%pip install requests
```

Это надёжнее, чем `!pip install`, так как `%pip` гарантированно использует pip, связанный с Python ядра.

### Справка по magics

```python
%magic      # общая справка
%lsmagic    # список всех магических команд
```

## Частые ошибки

### Ошибка 1 — Путать `!` и `%`

`!команда` — вызов shell. `%команда` — вызов magic IPython. `!ls` выполнит `ls` в shell. `%ls` покажет файлы через IPython (по сути то же, но работает иначе внутри). Для `pip` лучше `%pip` — он привязан к ядру.

### Ошибка 2 — `!pip install` ставит не туда

`!pip` вызывает тот pip, который shell найдёт по PATH. Если Jupyter запущен из venv, обычно всё ок. Но `%pip` — безопаснее: он всегда использует pip текущего ядра.

### Ошибка 3 — Cell magic не в первой строке

`%%time` или `%%capture` должны быть в **первой строке** ячейки. Иначе интерпретатор не распознает их как cell magic.

### Ошибка 4 — Ожидать, что `%run` изолирует переменные

По умолчанию `%run script.py` выполнит скрипт, и переменные из скрипта попадут в пространство имён ноутбука. Если нужна изоляция — используйте `%run -n` (в новом пространстве имён) или запускайте скрипт через `!python script.py`.
