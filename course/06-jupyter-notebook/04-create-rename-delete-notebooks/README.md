# Создание, переименование и удаление ноутбуков

> **Модуль 6 · Урок 4** | Время: ~10 мин

## Создание нового ноутбука

В файловом менеджере Jupyter (Dashboard):

1. Нажмите **New** в правом верхнем углу.
2. Выберите **Python 3 (ipykernel)** (или другое ядро, если установлено).

Откроется новая вкладка с пустым ноутбуком. Файл сохраняется в корневой директории сервера; имя по умолчанию — `Untitled.ipynb` или `Untitled1.ipynb`, если уже есть такой файл.

**Ноутбук** (notebook)[^глоссарий]([Глоссарий](../../references/glossary.md)) — документ формата `.ipynb` (JSON), содержащий ячейки с кодом и текстом. Каждая ячейка имеет тип (Code, Markdown, Raw) и содержимое.

## Переименование ноутбука

**Через вкладку браузера:** заголовок вкладки показывает текущее имя файла (без расширения). Клик по заголовку — не переименовывает файл.

**Через интерфейс Jupyter:**

1. Откройте меню **File** в верхней панели.
2. Выберите **Rename**.
3. Введите новое имя (например, `analysis.ipynb`) и подтвердите.

Или: в файловом менеджере нажмите на имя файла — появится поле редактирования.

**Важно:** имя файла определяет путь на диске. Расширение `.ipynb` обычно оставляют.

## Удаление ноутбука

**В файловом менеджере:**

1. Отметьте галочкой файл.
2. Нажмите **Delete** (или иконку корзины).
3. Подтвердите удаление.

Файл удаляется с диска. В некоторых версиях Jupyter есть корзина (Trash) — тогда файл сначала попадает туда, и его можно восстановить.

**Перед удалением:** убедитесь, что важные изменения сохранены (Ctrl+S). Jupyter по умолчанию сохраняет при каждом выполнении ячейки, но лучше не полагаться только на автосохранение.

## Расположение файлов

Файлы ноутбуков хранятся в той директории, откуда был запущен `jupyter notebook`. Если запуск из `~/projects/data-science`, все новые ноутбуки и папки создаются там. Можно создать подпапки через **New → Folder** и организовать проект.

## Частые ошибки

### Ошибка 1 — Удалить ноутбук без бэкапа

Удаление через интерфейс Jupyter безвозвратно стирает файл (если нет корзины). Перед удалением экспортируйте важные ноутбуки в HTML или .py — `File → Download as`.

### Ошибка 2 — Путать заголовок вкладки и имя файла

Заголовок вкладки в браузере может отставать от переименования файла. Истинное имя — то, что видно в файловом менеджере и в заголовке после **File → Rename**.

### Ошибка 3 — Закрыть вкладку, думая, что удалили ноутбук

Закрытие вкладки не удаляет файл. Файл `.ipynb` остаётся на диске. Удалять нужно через файловый менеджер или команду `rm` в терминале.
