# Типы ячеек: Code, Markdown, Raw

> **Модуль 6 · Урок 5** | Время: ~15 мин

## Что такое ячейка

**Ячейка** (cell)[^глоссарий]([Глоссарий](../../references/glossary.md)) — элементарная единица содержимого ноутбука. Ноутбук состоит из последовательности ячеек; каждая ячейка имеет тип и собственное содержимое.

Три основных типа:

| Тип | Назначение |
|-----|------------|
| **Code** | Исполняемый Python-код. |
| **Markdown** | Текст с разметкой (заголовки, списки, формулы). |
| **Raw** | Текст «как есть», без обработки и исполнения. |

## Code — ячейка с кодом

Ячейка типа **Code** содержит Python-код. При выполнении (Shift+Enter или кнопка Run) код отправляется в ядро (интерпретатор Python), результат выводится под ячейкой.

Пример:

```python
print("Привет, Jupyter!")
2 + 2
```

Вывод:

```
Привет, Jupyter!
4
```

Переменные, определённые в одной ячейке, доступны в последующих — пока ядро живо. Порядок выполнения важен: если пропустить ячейку, переменная не будет определена.

## Markdown — ячейка с документацией

Ячейка типа **Markdown** содержит текст в формате [Markdown](https://ru.wikipedia.org/wiki/Markdown): заголовки, списки, **жирный** текст, `код`, ссылки, формулы LaTeX (в некоторых движках).

После выполнения (Shift+Enter) ячейка отображается как отформатированный текст, а не сырой разметка.

Пример:

```markdown
## Анализ данных

Мы загрузим данные и построим график.

- Шаг 1: импорт
- Шаг 2: визуализация
```

Отображается как заголовок, параграф и список.

## Raw — ячейка «как есть»

Ячейка типа **Raw** не исполняется и не обрабатывается как Markdown. Её содержимое вставляется в экспорт «как есть» — полезно для произвольного текста при экспорте в LaTeX или HTML с кастомной разметкой.

В повседневной работе Raw используется редко; чаще хватает Code и Markdown.

## Переключение типа ячейки

Через меню: выберите ячейку → **Cell → Cell Type** → **Code** / **Markdown** / **Raw**.

Горячие клавиши (в режиме команд, когда ячейка подсвечена, но курсор не в ней):

- **Y** — Code
- **M** — Markdown  
- **R** — Raw

Подробнее о режимах и клавишах — в следующем уроке.

## Частые ошибки

### Ошибка 1 — Писать код в ячейке Markdown

В Markdown код не выполняется. Вывод будет выглядеть как текст. Нужен тип Code для исполнения Python.

### Ошибка 2 — Забывать Run для Code-ячеек

Изменения в коде не применяются, пока ячейка не выполнена. После правок нажимайте Shift+Enter или Run. Ядро хранит состояние только после выполнения.

### Ошибка 3 — Запускать ячейки не по порядку

Jupyter позволяет выполнять ячейки в любом порядке. Если вы выполнили ячейку 5, пропустив 3 и 4, переменные из 3 и 4 не определены — возможны NameError. Рекомендуется **Run All** или последовательное выполнение сверху вниз.
