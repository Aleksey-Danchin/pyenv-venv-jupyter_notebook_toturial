# Тренажёр: Установка и запуск JupyterLab

> **Модуль 9 · Тренажёр 2** | Время: ~15 мин

## Цель

Установить JupyterLab в виртуальное окружение и запустить сервер, чтобы работать в современном интерфейсе Jupyter.

## Подготовка

- Python установлен (через pyenv или системный)
- Вы умеете создавать и активировать venv (модуль 4)
- Вы знакомы с Jupyter Notebook (модуль 6) и ядрами (модуль 7)

## Кратко о JupyterLab как пакете

[JupyterLab](../01-jupyterlab-intro/README.md) устанавливается как Python-пакет. Он использует тот же сервер, что и классический Jupyter Notebook: команда `jupyter notebook` и `jupyter lab` запускают один и тот же бэкенд. Файлы `.ipynb` открываются в обоих интерфейсах без изменений. Ядра (kernels) — общие: если вы зарегистрировали venv как ядро, оно будет доступно и в Notebook, и в JupyterLab.

## Шаг 1 — Создать и активировать venv

Создайте виртуальное окружение для JupyterLab (например, в `~/jupyterlab-demo`):

```bash
mkdir -p ~/jupyterlab-demo && cd ~/jupyterlab-demo
python -m venv .venv
source .venv/bin/activate
```

**Ожидаемый результат:** в приглашении терминала появляется префикс `(.venv)`.

> **Что произошло:** venv создан и активирован. Все последующие команды `python` и `pip` будут работать внутри этого окружения.

---

## Шаг 2 — Установить JupyterLab

Установите JupyterLab в активированном venv. Пакет `jupyterlab` включает сервер и интерфейс. Опционально можно установить и `notebook` — тогда будет доступен и классический интерфейс через `jupyter notebook`:

```bash
pip install jupyterlab
```

**Ожидаемый результат:**

```
Successfully installed jupyterlab-... jupyterlab-server-... (и другие зависимости)
```

> **Что произошло:** JupyterLab установлен. Команда `jupyter lab` станет доступна.

---

## Шаг 3 — Запустить JupyterLab

Запустите сервер JupyterLab. По умолчанию он откроет браузер и будет слушать порт 8888:

```bash
jupyter lab
```

**Ожидаемый результат:** в терминале появляется сообщение вида:

```
[I 2025-...] Jupyter Server ... is running at:
[I 2025-...] http://localhost:8888/lab?token=...
```

Браузер открывается с интерфейсом JupyterLab. Если порт 8888 занят (например, уже запущен Jupyter Notebook), используйте другой порт:

```bash
jupyter lab --port=8889
```

> **Что произошло:** JupyterLab запущен. Интерфейс доступен в браузере. Токен в URL обеспечивает доступ без пароля при локальной работе.

---

## Шаг 4 — Проверить версию (опционально)

Убедитесь, что JupyterLab установлен и команда указывает на ваш venv:

```bash
jupyter lab --version
which jupyter
```

**Ожидаемый результат:** версия JupyterLab (например, `4.x.x`), а `which jupyter` показывает путь внутри `.venv/bin/jupyter`.

---

## Итог

Вы установили JupyterLab в venv и запустили сервер. Интерфейс JupyterLab открыт в браузере. Вы можете создавать ноутбуки, терминалы и просматривать файлы в едином рабочем пространстве.

## Проверка

Выполните скрипт проверки (из директории юнита или указав полный путь):

```bash
bash check.sh
```

**Ожидаемый результат:** все пункты проверки помечены как PASS.
