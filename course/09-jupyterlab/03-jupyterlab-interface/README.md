# Интерфейс JupyterLab: вкладки, терминал, файловый менеджер, просмотр данных

> **Модуль 9 · Урок 3** | Время: ~20 мин

## Основной контент

После запуска `jupyter lab` в браузере открывается интерфейс [JupyterLab](course/references/glossary.md), заметно отличающийся от классического Jupyter Notebook. В этом уроке разберём основные элементы интерфейса.

### Структура интерфейса

Интерфейс JupyterLab состоит из:

- **Левая боковая панель** — содержит вкладки «Файлы», «Запущенные ядра и терминалы», «Команды» и др. Сворачивается по клику на иконку.
- **Основная область** — здесь отображаются открытые документы: ноутбуки, текстовые файлы, консоли. Каждый документ — во вкладке.
- **Launcher** — панель «Стартовая доска», которая появляется при первом открытии или через File → New Launcher. Здесь создаются ноутбуки, консоли, терминалы, текстовые файлы.

### Вкладки и перетаскивание

- Все открытые документы отображаются во вкладках. Можно перетаскивать вкладки, чтобы изменить порядок или объединить панели.
- Документы можно располагать в разных областях: разделить экран на две части — слева ноутбук, справа терминал. Перетащите вкладку к краю панели, пока не появится подсветка зоны.
- Закрыть вкладку — через крестик или File → Close Tab.

### Создание ноутбуков, терминала, файлов

Через **File → New** или Launcher:

- **Notebook** — создать новый ноутбук. Выбирается ядро (Kernel). Те же ядра, что и в Jupyter Notebook — зарегистрированные через ipykernel.
- **Console** — консоль IPython (интерактивная сессия без ячеек).
- **Terminal** — встроенный терминал. Запускает ваш default shell (bash). Важно: терминал наследует окружение из того процесса, в котором запущен Jupyter. Если вы запустили `jupyter lab` из активированного venv, то и терминал внутри JupyterLab будет видеть этот venv — `python` и `pip` указывают на окружение.
- **Text File** — пустой текстовый файл (например, для заметок или .py без ноутбука).

### Встроенный терминал

Терминал в JupyterLab — это полноценный shell. Он запускается в том же окружении, что и сервер Jupyter. Если JupyterLab запущен из активированного venv, то в терминале `which python` покажет Python из этого venv.

Использование терминала удобно, когда нужно:
- выполнить команды (`pip install`, `git`, `ls`) не выходя из браузера;
- запустить скрипт и посмотреть вывод рядом с ноутбуком;
- работать с файлами в директории проекта.

### Файловый менеджер

В левой панели (вкладка «Файлы») — браузер файлов. Корень — директория, из которой запущен `jupyter lab`. Можно:
- переходить по папкам;
- создавать новые файлы и папки (правый клик);
- переименовывать, удалять;
- перетаскивать файлы.

Двойной клик на `.ipynb` открывает ноутбук в новой вкладке. Двойной клик на `.py` или `.md` открывает текстовый редактор.

### Просмотр данных без кода

JupyterLab умеет отображать некоторые форматы данных «из коробки»:

- **CSV** — двойной клик открывает табличное представление с сортировкой по столбцам.
- **Изображения** (PNG, JPG, SVG и др.) — открываются в режиме просмотра, можно масштабировать.
- **JSON** — отображается с подсветкой синтаксиса.

Это удобно для быстрого просмотра данных без написания кода — достаточно открыть файл в файловом менеджере.

### Горячие клавиши

Большинство горячих клавиш Jupyter Notebook работают и в JupyterLab: `Shift+Enter` (выполнить ячейку), `Ctrl+Enter` (выполнить без перехода), `Esc` / `Enter` (режим команд / режим редактирования). Полный список — Help → Keyboard Shortcuts.

## Частые ошибки

### Ошибка 1 — Терминал в JupyterLab не видит venv

Если `which python` в терминале JupyterLab показывает системный Python — JupyterLab был запущен не из активированного venv. Остановите сервер (Ctrl+C в терминале, где он запущен), активируйте venv, снова запустите `jupyter lab`. Терминал наследует окружение процесса Jupyter.

### Ошибка 2 — Не найти Launcher

Launcher появляется при пустой рабочей области. Если все вкладки закрыты, откройте File → New Launcher. Или File → New → Notebook / Terminal — создастся нужный ресурс и откроется Launcher при необходимости.

### Ошибка 3 — Путать вкладку «Файлы» и «открытые документы»

«Файлы» в боковой панели — это навигация по диску. Открытые документы (ноутбуки, файлы) — во вкладках в основной области. Чтобы открыть файл в редакторе/просмотрщике, нужен двойной клик в «Файлах» или File → Open.

### Ошибка 4 — CSV открылся как текст

Если CSV отображается как сырой текст — возможно, расширение не `.csv` или MIME-тип не распознан. Проверьте расширение файла. Для больших CSV JupyterLab может предложить только частичную загрузку.
