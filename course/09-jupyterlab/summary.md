# Конспект: Модуль 9 — JupyterLab

> Краткий справочник для повторения. Подходит для печати.

## Ключевые понятия

| Понятие | Суть (1 предложение) |
|---------|---------------------|
| **JupyterLab** | Веб-интерфейс нового поколения для Jupyter: вкладки, терминал, файловый менеджер, просмотр данных в одном окне. |
| **Launcher** | Стартовая панель JupyterLab для создания ноутбуков, терминалов, текстовых файлов. |
| **боковая панель** | Левая панель с файловым менеджером и вкладками; можно скрыть и открыть. |

## Важно запомнить

- JupyterLab и Jupyter Notebook используют один и тот же сервер и форматы файлов (.ipynb).
- Пакет `jupyterlab` устанавливается отдельно от `jupyter notebook`; оба могут быть в одном venv.
- Встроенный терминал JupyterLab наследует окружение процесса Jupyter (venv, если запущен из него).
- Все зарегистрированные ядра (ipykernel) доступны и в Notebook, и в JupyterLab.

## Команды модуля

```bash
pip install jupyterlab          # Установить JupyterLab в venv
jupyter lab                     # Запустить JupyterLab (порт 8888 по умолчанию)
jupyter lab --port 8889         # Запустить на другом порту
jupyter lab --version           # Показать версию JupyterLab
```

## Типичные ошибки (коротко)

| Ошибка | Причина | Решение |
|--------|---------|---------|
| JupyterLab не запускается | Пакет не установлен или не в активированном venv | `pip install jupyterlab`, активировать venv |
| Ноутбук выполняется в системном Python | Ядро по умолчанию — системное | Kernel → Change kernel → выбрать venv |
| Терминал не видит venv | JupyterLab запущен не из venv | Запускать `jupyter lab` из активированного venv |
| Порт 8888 занят | Другой Jupyter уже работает | `jupyter lab --port 8889` или остановить другой сервер |

## Схема

```
venv (активирован)
    │
    ├── pip install jupyterlab
    │
    └── jupyter lab
            │
            ├── Ноутбуки (.ipynb) — те же ядра, что и в Notebook
            ├── Терминал — окружение venv
            ├── Файловый менеджер — навигация по файлам
            └── Просмотр CSV/изображений — без кода
```
