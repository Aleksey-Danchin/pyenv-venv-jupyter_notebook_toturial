# Что такое JupyterLab и чем отличается от Notebook

> **Модуль 9 · Урок 1** | Время: ~15 мин

## Основной контент

**JupyterLab** — это «следующее поколение» интерфейса Jupyter (Next-Generation Notebook Interface). JupyterLab не заменяет Jupyter Notebook по смыслу работы с ноутбуками, но предоставляет более мощный и расширяемый интерфейс.

JupyterLab — единая веб-среда, в которой вы работаете с ноутбуками, текстовыми файлами, терминалом, просматриваете данные и код. Классический Jupyter Notebook — это один ноутбук на странице. JupyterLab — модульный интерфейс с вкладками, боковыми панелями и возможностью открыть несколько ноутбуков, терминал и файловый менеджер одновременно.

### Зачем JupyterLab

- **Модульность:** ноутбуки, терминал, просмотр файлов — всё в одном окне, переключаетесь вкладками.
- **Встроенный терминал** — не нужно открывать отдельное окно терминала.
- **Просмотр данных** без кода — CSV, изображения, JSON отображаются прямо в интерфейсе.
- **Расширяемость** — плагины и расширения для JupyterLab добавляют функции.
- **Официальное направление развития** — Jupyter Project рекомендует JupyterLab как основную среду для работы с ноутбуками.

### Основные отличия от классического Notebook

| Аспект | Jupyter Notebook | JupyterLab |
|--------|------------------|------------|
| Интерфейс | Один документ на странице | Модульный: вкладки, панели, перетаскивание |
| Терминал | Отдельно (вне Jupyter) | Встроенный в интерфейс |
| Файлы и данные | Через браузер файлов | Файловый менеджер + просмотр CSV/изображений |
| Ячейки и ядра | Те же | Те же, работа идентична |
| Формат .ipynb | Полная совместимость | Полная совместимость |

Ноутбуки (.ipynb) открываются и в Notebook, и в JupyterLab без изменений. Ядра, магические команды, типы ячеек — всё работает одинаково. Разница только в интерфейсе и удобстве организации работы.

### Когда выбирать JupyterLab

- Работа с несколькими ноутбуками и файлами одновременно.
- Нужен встроенный терминал в той же среде.
- Просмотр CSV, изображений без написания кода.
- Желание использовать современный интерфейс Jupyter.

## Сравнение с альтернативами

### Jupyter Notebook vs JupyterLab vs VS Code Notebooks

| Инструмент | Суть | Плюсы | Минусы |
|------------|------|-------|--------|
| **Jupyter Notebook** | Классический веб-интерфейс | Простой, привычный, лёгкий | Один документ на экран, нет встроенного терминала |
| **JupyterLab** | Расширенный веб-интерфейс Jupyter | Вкладки, терминал, просмотр файлов, модульность | Чуть тяжелее Notebook |
| **VS Code Notebooks** | Ноутбуки внутри редактора VS Code | Интеграция с IDE, отладка, git | Другой контекст, не веб, привязка к VS Code |

Jupyter Notebook и JupyterLab — родственные продукты: оба из экосистемы Jupyter, используют одни ядра и формат .ipynb. VS Code Notebooks — реализация того же формата в редакторе кода. Выбор зависит от привычки: если работаете в браузере — JupyterLab; если в IDE — VS Code.

## Частые ошибки

### Ошибка 1 — Думать, что JupyterLab и Notebook — разные программы

Оба — части экосистемы Jupyter, используют один сервер и одни ядра. `jupyter notebook` и `jupyter lab` — разные точки входа в один и тот же Jupyter. Ноутбуки, созданные в одном, открываются в другом без изменений.

### Ошибка 2 — Устанавливать JupyterLab вместо Jupyter, ожидая только Lab

Пакет `jupyter` — мета-пакет, который тянет notebook и другие компоненты. `jupyterlab` — отдельный пакет. Часто ставят `pip install jupyter jupyterlab` — тогда доступны оба интерфейса. Для одного JupyterLab достаточно `pip install jupyterlab`.

### Ошибка 3 — Путать «интерфейс» и «ядро»

JupyterLab и Notebook — это интерфейсы (как открыть и отображать ноутбук). Ядро — среда выполнения кода (Python, пакеты). Ядра, зарегистрированные через ipykernel, работают и в Notebook, и в JupyterLab одинаково.
