# Модуль 9. JupyterLab

> **Время:** ~1–2 дня (при темпе 1–2 часа в день)

## Чему вы научитесь

- Понимать, чем JupyterLab отличается от классического Jupyter Notebook
- Устанавливать и запускать JupyterLab внутри venv
- Ориентироваться в интерфейсе: вкладки, терминал, файловый менеджер, просмотр данных
- Переносить рабочий процесс с Notebook на JupyterLab (миграция)

## Что будет рассмотрено

| Тема | Описание |
|------|----------|
| JupyterLab и его отличия | Next-Generation Notebook Interface, модульность, расширяемость |
| Установка и запуск | pip install jupyterlab, jupyter lab, порты |
| Интерфейс | Боковая панель, Launcher, вкладки, встроенный терминал, просмотр CSV и изображений |
| Миграция с Notebook | Открытие существующих ноутбуков, сравнение опыта работы |

## Инструменты и команды

| Команда / инструмент | Назначение |
|---------------------|-----------|
| `pip install jupyterlab` | Установить JupyterLab в активированное venv |
| `jupyter lab` | Запустить JupyterLab (сервер по умолчанию на порту 8888) |
| `jupyter lab --port=<N>` | Запустить JupyterLab на указанном порту |

## Итоги модуля

### Что вы изучили

- **JupyterLab** — наследник и замена классического Jupyter Notebook: модульный интерфейс, вкладки, встроенный терминал, файловый менеджер, просмотр данных без кода.
- Установка: `pip install jupyterlab` в venv; запуск: `jupyter lab` (тот же сервер, что и для Notebook).
- Launcher — точка входа для создания ноутбуков, терминалов, текстовых файлов.
- Миграция: существующие .ipynb файлы открываются в JupyterLab без изменений; ядра работают так же.

### Чеклист навыков

Отметьте то, что вы уверенно можете сделать:

- [ ] Объяснить основные отличия JupyterLab от Jupyter Notebook
- [ ] Установить JupyterLab в venv и запустить сервер
- [ ] Создать ноутбук и терминал через Launcher
- [ ] Открыть существующий .ipynb в JupyterLab и выполнить ячейки
- [ ] Просмотреть CSV или изображение в JupyterLab без написания кода
- [ ] Использовать встроенный терминал рядом с ноутбуком

### Ключевые команды

```bash
pip install jupyterlab
jupyter lab
jupyter lab --port=8889
```
